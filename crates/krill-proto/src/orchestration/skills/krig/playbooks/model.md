# Model Playbook (Finite State-Space BFS Verification & Counterexample Reproduction)

## Trigger

Run in `afk` gear when designing, modifying, or exhaustively verifying multi-step interleaved logic where deadlocks or invariant violations can occur (retries, checkpoint recovery, leases, payment transitions, concurrency protocols). Chains into [drive.md](drive.md) when implementation is requested, or [verify.md](verify.md) for verification-only tasks.

## Steps

1. **Extract a finite state-space model.** Write `.krig/models/<name>.json` or `.mjs` specifying state variables (abstracted to finite domains, using `null` instead of `undefined`), `initial` state, atomic `actions` with guards and nondeterministic failure branches, non-empty `terminal` predicates, safety `invariants`, and `mustReach` targets that prevent vacuous passes.
   - **Supported predicate operators (`when` / `invariants` / `mustReach` / `terminal`)**: literal equality, `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, cross-path references (`$eqRef`, `$neRef`, `$ltRef`, `$lteRef`, `$gtRef`, `$gteRef`), and boolean combinators (`$and`, `$or`, `$not`, `$implies: [premise, conclusion]`).
   - **Supported state mutation operators (`set`)**: literal assignment, `$inc`, `$dec`, `$ref` (copy another path), `$toggle`, `$append`. For richer pure transitions, export a `.mjs` spec with `export default { initial, terminal, actions: [{ name, guard: (s) => ..., apply: (s) => nextOrArray }], invariants, mustReach }`.

```json
{
  "initial": { "phase": "queued", "delivered": 0, "checkpointed": false },
  "terminal": [{ "phase": "done" }, { "phase": "quarantined" }],
  "actions": [
    {
      "name": "deliver_and_crash_or_ack",
      "when": { "phase": "queued" },
      "branches": [
        { "label": "ack", "set": { "phase": "done", "delivered": { "$inc": 1 }, "checkpointed": true } },
        { "label": "crash_in_flight", "set": { "phase": "ambiguous", "delivered": { "$inc": 1 } } }
      ]
    },
    {
      "name": "quarantine_uncertain_boot",
      "when": { "phase": "ambiguous", "checkpointed": false },
      "set": { "phase": "quarantined" }
    }
  ],
  "invariants": {
    "AtMostOnceConfirmedDelivery": { "delivered": { "$lte": 1 } }
  },
  "mustReach": {
    "CanCompleteCleanly": { "phase": "done" },
    "CanQuarantineAmbiguousCrash": { "phase": "quarantined" }
  }
}
```

2. **Run exhaustive breadth-first exploration.** Invoke [statecheck.mjs](../scripts/statecheck.mjs) with `--require-complete` to explore all reachable states within bounds and verify invariants, deadlock freedom (`NoDeadlock`), and `mustReach` targets in one pass:

```bash
node "<SKILL_DIR>/scripts/statecheck.mjs" --require-complete .krig/models/<name>.json
node "<SKILL_DIR>/scripts/statecheck.mjs" --mermaid .krig/models/<name>.json
```

3. **Reproduce the shortest counterexample in real code and fix.**
   - If exit code is `1` (violation found), check whether the shortest counterexample trace (`step 0, step 1, ...`) reflects a modeling typo or a real production defect.
   - For real production defects, first write a **failing behavioral test** reproducing the exact action sequence, confirm red failure, then fix both the model and production code until `statecheck.mjs` and the test suite exit `0`.
4. **Visualize and hand off the verified graph.** Attach the `stateDiagram-v2` generated by `statecheck.mjs --mermaid` directly from the explored graph instead of hand-drawn speculative diagrams.

## Rules

- Even when invariants pass, failure to reach a normal `mustReach` completion state indicates over-constrained guards (vacuous pass) and must be fixed.
- Bound unbounded counters (such as retry counts) to meaningful finite limits (e.g., max `2-3` retries) so exploration completes with `complete=true`.

## Verification

- Verify `node "<SKILL_DIR>/scripts/statecheck.mjs" --json --require-complete <spec_file>` outputs `ok: true`, `complete: true`, and `violations: []`.
- When production code was also changed, confirm the full test suite including the counterexample regression test exits `0`.
