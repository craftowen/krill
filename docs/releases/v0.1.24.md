# Krill v0.1.24 릴리스 노트

## 새 에이전트 세션

- 새 세션은 기본적으로 YOLO 권한으로 실행합니다. Claude Code·Codex 등 각 프로필의 승인 우회 인자를 적용합니다.
- `permission = "manual"`과 `yolo_mode = false`를 명시한 기존 설정은 유지합니다. 전역 권한 토글과 세션별 배지로 실행 권한을 확인할 수 있습니다.
- 기본 권한 적용과 데몬 재시작 후 세션 재개 동작의 회귀 검증을 보강했습니다.

## 야간 자동 릴리스

- 매일 한국시간 자정에 원격 dev와 main을 고정해 검증·배포하는 예약 실행기를 추가했습니다. 예약 등록과 상태 조회는 `packaging/README.md`에 설명합니다.
- 예약 실행은 Orca의 일반 셸에서 수행하며 원본 개발 체크아웃과 이미 진행 중인 릴리스를 분리합니다.
- 전체 검사·메모리·세션 생존 검사와 Windows·Linux 네이티브 빌드를 통과한 동일 커밋을 공식 게시 경로로 배포합니다.
- 빌드 전용 네이티브 CI와 검증된 자산 반입을 지원하고, 기존 태그·릴리스 덮어쓰기와 유료 VM 실행은 허용하지 않습니다.

## 모바일

- 실행 중인 PWA가 연결한 데스크톱과 호환되는 새 화면을 확인하고, 파일·해시·캐시 준비를 마친 뒤 안전한 시점에 갱신합니다.
- 갱신 기능을 지원하는 버전 사이에서 인증·현재 화면·채팅 초안·터미널 입력 버퍼를 같은 탭에 보존합니다. 한글 입력·전송·사진 처리 중이거나 전송 결과가 불확실하면 전환을 미룹니다.
- 호스트를 바꾼 뒤 이전 호스트의 초안이나 늦게 처리된 사진·입력이 새 호스트에 섞이지 않도록 보완했습니다.
- 프로젝트 목록에 좌우 여백을 넣고 하위 작업 공간 행을 들여써 목록 계층을 구분합니다.
