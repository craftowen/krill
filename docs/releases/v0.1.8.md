# Krill v0.1.8 릴리스 노트

## 새 기능

- **관리형 원격 서버 연결 및 자동 설치·업데이트**: SSH 원격 호스트의 운영체제·아키텍처를 감지하고, macOS 원격에는 앱에서 `krill`을 바로 설치·업데이트하며 버전·프로토콜 호환 상태를 표시합니다. Linux 원격은 `install-linux.sh`로 설치한 뒤 연결합니다(앱 자동 설치는 macOS만) (OWE-897).
- **모바일 웹앱(PWA) 워크스페이스 셸 및 라이브 터미널 입력**:
  - 모바일 화면을 저장소·워크트리 그룹 단위로 구성하고 세션 상태 근거와 호스트 정보를 함께 보여주며, 모바일에서 바로 새 터미널 세션을 만들거나 닫을 수 있습니다 (OWE-895).
  - 모바일 터미널 뷰에서 직접 IME 입력, 전달 확인(ACK) 기반 키 입력, 보조 특수키 바를 지원합니다.
- **명령 팔레트(`⇧⌘P`) 및 빠른 이동(`⌘J`) 통합**: 명령 팔레트와 Jump 팔레트에서 워크트리·액션·빠른 명령을 검색하고 `⌘1`~`⌘9` 단축키로 항목을 즉시 실행할 수 있습니다 (OWE-865, OWE-862).
- **앱 재시작·재부팅 후 작업 화면 복원 및 콜드 자동 재스폰**: 창 위치·크기, 사이드바 선택·필터·접힘 상태, 우측 패널·열린 파일 탭, 원격 호스트 연결을 복원하고 재부팅 후 콜드 세션을 자동으로 다시 띄웁니다 (OWE-842).
- **터미널 URL 열기·선택·검색·스크롤백 제어**:
  - 터미널 안의 평문 `http(s)` URL과 OSC 8 하이퍼링크에 `⌘+호버` 밑줄 표시 및 `⌘+클릭` 브라우저 열기를 지원합니다 (OWE-867).
  - 더블클릭 단어 선택, 트리플클릭 줄 선택, `Shift+클릭` 선택 영역 확장을 지원합니다 (OWE-866).
  - 터미널 검색에서 스크롤백 위치 이동, 다중 매치 하이라이트, 이전/다음 결과 이동 단축키를 지원합니다 (OWE-868).
  - 터미널 스크롤바와 '맨 아래로' 이동 배지, `⌘K` 스크롤백 비우기를 추가했습니다. 데몬 스크롤백도 비우고 디스크 기록에서도 제외해서 다시 붙거나 앱을 재시작해도 지운 줄이 돌아오지 않습니다. 구버전 데몬과는 화면 쪽만 비웁니다 (OWE-873).
- **분할 패인·탭 제어 및 실행 중 닫기 보호**:
  - 탭 더블클릭·우클릭 메뉴 이름 변경, 왼쪽 탭 닫기, 마우스 휠 클릭 탭 닫기를 지원합니다 (OWE-870).
  - 분할 패인 헤더 기록, 줌 해제, 방향 이동, 빈 커서 표시, 상태 배지, 분할선 드래그, 우클릭 메뉴를 지원합니다 (OWE-871).
  - 작업이 실행 중인 탭이나 분할 칸을 닫을 때 확인 모달을 표시하며 '다시 묻지 않기' 선택을 유지합니다 (OWE-872).
- **에디터·파일 탐색기 및 Git 변경 사항 패널 확장**:
  - 에디터에서 줄·열 번호 점프 시 편집 모드 진입, SVG 버퍼 미리보기, 에디터 내 찾기(`⌘F`), 긴 줄 자동 줄바꿈(wrap), 파일 탭 경로 메뉴를 지원합니다 (OWE-874).
  - 파일 탐색기·전문 검색 비동기 디바운스, 미리보기 탭, 상대 경로 표시, 인라인 편집을 지원합니다 (OWE-849).
  - 변경 사항 패널(`⌘⇧G`)에서 탭 필터링, 변경 취소(Discard), 여러 줄 커밋 메시지 작성 및 `⌘Enter` 커밋을 지원합니다 (OWE-848).
- **단축키 설정 탭 개편**: 카테고리별 그룹, 로컬 검색, 상태 필터, 인라인 단축키 녹음기(수식키 검증·개별 삭제·사용 안 함 지정 포함), 행별 초기화를 지원합니다 (OWE-799, OWE-863).
- **GitHub 별(Star) 요청 카드**: 에이전트 세션을 일정 횟수 이상 시작한 뒤 메인 창 우하단에 GitHub 별 요청 카드를 표시하며 '나중에'와 '다시 보지 않기'를 지원합니다 (OWE-905).

## 개선

- **첫 실행 온보딩 간소화 및 메인 창 인앱 모달 통합**:
  - 첫 실행 시 작업을 가로막던 동의·기본 에이전트 선택·Orca 가져오기 모달을 제거하고 백그라운드 자동 준비로 즉시 시작하도록 간소화했습니다 (OWE-904).
  - 설정 점검과 기기 페어링 화면을 별도 OS 창 대신 메인 창 안 모달로 통합하고 `⌘W`·`Esc` 닫기를 지원합니다 (OWE-903, OWE-878).
- **Orca 이관 및 다계정·사용량 연동 개선**:
  - Orca 인증을 바로 이관할 때 키체인 경로를 일치시키고 UUID·이메일/조직 기준 중복 계정을 병합하며, Antigravity(`agy`) 감지·연결 상태 표시와 실시간 사용량 조회·한도 전환·호스트 판정 폴백을 지원합니다 (OWE-896, OWE-901).
  - Orca 이관 시 심볼릭 링크 경로를 정규화해 사이드바 중복 표시를 막고, 이관 후 사이드바 항목을 카드 형태로 그리며 유휴 프로젝트가 많을 때 자동으로 접습니다 (OWE-803, OWE-900).
  - Orca 가져오기 요약에서 0건 항목과 불필요한 영문 병기를 숨기고 코멘트 수 집계·모달 취소 버튼을 정리했습니다 (OWE-882).
  - 프로바이더 계정이 하나뿐이면 서브메뉴 없이 바로 세션을 실행하며, 계정 지정 실행에도 선택한 실행 호스트(`launch_host`)를 적용합니다 (OWE-879).
  - 계정 로그인 진행 표시·취소·실패 안내와 OpenCode 실행 전 안내를 보강하고, 모든 프로바이더 표기 지점에 브랜드 색상 아이콘을 일관되게 적용했습니다 (OWE-881, OWE-875).
- **사이드바·워크트리·프로젝트 관리 UX**:
  - 사이드바 저장소 헤더 접기/펼치기 화살표·우클릭 메뉴·접힘 상태 저장을 지원하고, 단일 세션 카드 선택과 세션 행 전용 컨텍스트 메뉴를 분리했습니다 (OWE-845, OWE-854).
  - 워크트리 카드 인라인 이름 변경·삭제 확인 모달·강제 삭제 경로를 추가하고, 새 워크트리 생성 시 기준 브랜치 드롭다운(현재 브랜치 기본값)과 생성 후 자동 전환을 지원합니다 (OWE-847, OWE-853).
  - 프로젝트 추가 결과를 영속 저장하고 모달 키보드 이동과 단계별 `Esc` 복귀를 지원합니다 (OWE-852).
  - 사이드바 PR 경고 닫기, `gh` 조회 쿨다운 분리, PR·CI 배지 클릭 이동을 지원하며, 창이 숨겨진 동안 패치·Checks 폴링을 멈추고 재활성화 시 불필요한 상태 재계산을 줄였습니다 (OWE-850, OWE-898).
- **모바일 터널·연결 유지 및 설정 탭 사용성**:
  - Cloudflare Quick Tunnel이 외부 HTTP 응답 준비를 마친 뒤 QR을 발급하며, 연결 모드 영속 저장, `cloudflared` 감시·자동 재기동, WebSocket ping 및 자동 재접속을 지원합니다.
  - 설정 모바일 탭 진입 시 기기 목록을 자동 조회하고 전체 해제 확인, 복사 피드백, 상태·경과 시간 표기를 개선했습니다 (OWE-880).
- **SSH 호스트 설정·글꼴·줌·메뉴·접근성·디자인 시스템 정합화**:
  - SSH 호스트 폼 `Enter` 제출, 연결 테스트 진행 표시, 삭제 확인, `ssh-copy-id` 결과 배너 안내를 추가했습니다 (OWE-884).
  - `⌘=`/`⌘-`/`⌘0`을 포커스 영역별(터미널·에디터·이미지) 확대로 분리하고 앱 전체 UI 배율은 설정 화면에서 조절하도록 정리했습니다 (OWE-843).
  - 터미널 글꼴 고정폭 폴백과 설정 가져오기 검증·경고를 추가했습니다 (OWE-899).
  - macOS 상단 메뉴(편집·보기·윈도우·도움말), 상태바 설정 라벨·세션 히스토리 팝오버, 대시보드·리소스 화면 키보드 탐색(`Esc`·포커스 이동) 및 VoiceOver 접근성 역할·상태 표기를 보강했습니다 (OWE-851, OWE-856, OWE-857, OWE-864).
  - 사이드바·셸·탭·패인 헤더·모달·팔레트·팝오버·우측 패널·파일 뷰어·온보딩·계정·페어링 전반의 디자인 토큰·프리미티브를 통일하고 디버그 포맷·영문 노출을 한국어/다국어 카탈로그 문구로 교체했습니다 (OWE-883, OWE-885, OWE-886, OWE-887, OWE-888, OWE-889, OWE-890).
  - `install.sh`에서 Intel Mac 실행 시 소스 빌드 절차를 안내하도록 개선했습니다.

## 버그 수정

- 첫 실행 온보딩·기기 페어링 모달을 열 때 `Shell` 상태 재진입으로 앱 시작 직후 발생하던 패닉을 호스트 디스패치 지연으로 수정했습니다 (OWE-903).
- 모든 탭을 닫은 빈 상태에서 발생할 수 있던 `active_tab` 패닉을 제거하고 빈 상태 안내 화면과 첫 탭 생성을 복구했습니다 (OWE-869).
- 콜드 세션 자동 재스폰 시 저장된 작업 디렉터리(`cwd`)가 덮어써지던 회귀를 수정했습니다 (OWE-842).
- `⌘N`이 새 창과 새 워크트리에 함께 걸리던 충돌을 해소했습니다. 이제 `⌘N`은 새 워크트리, `⇧⌘N`은 새 창이며, 이미 열린 메인 창은 재사용합니다 (OWE-859).
- 설정 화면에서 Shell 키 컨텍스트 유지, `⌘,` 토글, 탐색 단축키 실행 시 설정을 닫고 전환하는 동작, 팝아웃·점검 창 단축키 동작, 설정 닫힘 시 메인 창 제목(`Krill`) 복원을 수정했습니다 (OWE-855, OWE-860, OWE-861).
- 워크트리 카드 호버 버튼 겹침, 브랜치 이름 중복 표시, 배지 찌그러짐, 가상 리스트 항목 클릭 불가 문제를 수정했습니다 (OWE-846).
- 설정 점검 모달에서 hook 인라인 diff 미리보기가 누락되거나 오류가 잘못 표시되던 문제를 수정했습니다 (OWE-877).
- 상태바 메뉴가 열려 있을 때 호버 툴팁이 함께 뜨던 문제와 대시보드 미리보기 중복 표시를 수정했습니다 (OWE-851, OWE-861).
- 모바일 PWA에서 인증 직후 WebSocket 연결이 끊기면 세션 목록이 빈 상태로 남던 문제를 저장된 자격증명 자동 재접속으로 수정했습니다.
- 원격 SSH 터널 프로세스가 강제 종료(`SIGKILL`)된 뒤 남던 포워딩 소켓(`fwd-*.sock`)을 다음 터널 시작 때 자동 정리하도록 수정했습니다.
- macOS JXA 권한 프로브에서 `CGPreflightScreenCaptureAccess`가 노출되지 않는 환경에서도 상태 조회가 실패하지 않도록 수정했습니다 (OWE-902).
- 온보딩 상태 파일 원자 쓰기 경로 누락을 수정했습니다 (OWE-905).
- 모바일 PWA에서 인증이 거부되면 같은 자격증명으로 끝없이 다시 접속하던 문제를 수정했습니다. 게이트웨이가 거부 코드(1008)로 닫고, 클라이언트는 2회까지만 간격을 늘려 재시도합니다.

## 알려진 제한

- **Windows 포팅(M11)은 소스만 포함**: Windows 빌드 코드(ConPTY·DPAPI·rename 업데이트)가 이번 버전 소스에 들어왔지만 Windows 설치 파일은 배포하지 않습니다. GCP Windows Server VM에서 헤드리스로만 실측했고, Windows 10/11 데스크톱 GUI·한글 IME는 아직 미확인입니다.
- **Apple Silicon 전용 릴리스 번들 및 Gatekeeper**: 배포되는 사전 빌드 앱 번들(`.dmg`/`.zip`)은 Apple Silicon(`arm64`) 전용이며 Intel Mac에서는 소스 빌드(`install.sh --from-source`)를 사용해야 합니다. Apple Developer ID 공증 전까지(MK-104) 브라우저에서 직접 내려받은 번들은 Gatekeeper 경고가 표시될 수 있으며, `install.sh`로 설치하면 격리 속성이 함께 정리됩니다.
- **Linux 원격 호스트 세션 유지 조건**: Linux 원격 호스트에서 `systemd-logind`의 `KillUserProcesses=yes`가 활성화된 경우 SSH 연결이 닫힐 때 원격 데몬이 종료될 수 있으므로 `KillExcludeUsers` 설정 또는 사용자 linger 활성화가 필요합니다.
- **모바일 외부 터널(Quick Tunnel) 주소 변경**: Cloudflare Quick Tunnel(`--tunnel`)은 고정 주소를 제공하지 않으므로 터널 프로세스가 재시작되면 접속 URL이 바뀌며 QR 코드를 다시 스캔해야 합니다.
