# Krill v0.1.37 릴리스 노트

v0.1.36 이후 변경은 다음과 같다. 이번 버전은 재부팅 뒤 세션 복원, 에이전트 대화 기록 공용화, 모바일 퀵터널 제거를 다룬다.

## 재부팅·데몬 재시작 뒤 세션 복원

holder와 krilld가 함께 꺼진 뒤(재부팅과 같은 상황) 셸·에이전트 프로세스는 새로 뜬다. 이번 버전부터 이전 모습을 이어 붙인다.

- 화면에 보이지 않던 탭·워크트리의 세션도 복원한다. 전에는 보이는 칸만 복원했다. 사이드바에서 그 폴더를 열면 저장된 Claude 세션 대신 새 셸이 열렸다.
- 사이드바에서 폴더를 열면 저장된 작업 공간을 먼저 연다. `+`와 새 에이전트 버튼은 전처럼 새 세션을 만든다.
- 이전 화면과 스크롤백을 새 세션의 기록으로 디스크에 연결한다. 탭을 옮기거나 앱을 다시 켜도 남고, 1,000행을 넘는 이전 기록도 끝까지 읽힌다. 전에는 메모리에만 있어 탭을 옮기면 사라졌다.
- 이전 화면 기록이 없어도 에이전트 대화를 재개한다(`claude --resume`, `codex resume`). 전에는 기록이 없으면 셸을 만들었다.
- 에이전트를 재개할 때 처음 실행한 폴더가 아니라 마지막에 있던 폴더에서 잇는다.
- 앱을 켤 때마다 krilld가 하나 더 떴다가 `listener failed`로 끝나던 오류를 고쳤다. 버전 확인 인자를 소켓 경로로 읽던 문제였다.
- 데몬·앱 사이 기능 비트 `FEAT_RESUME_HISTORY`(`1 << 30`)를 더했다. 이전 버전 데몬과 붙으면 기존 동작을 유지한다.
- 격리 환경에서 holder·krilld를 두 번 연달아 강제 종료하는 시험으로 확인했다. 실제 Mac 재부팅으로는 아직 확인하지 않았다.

## 에이전트 대화 기록을 기본 저장소에 모음

Krill이 계정별로 만든 프로필이 대화 기록을 따로 가지고 있어서, 같은 폴더·같은 브랜치여도 Orca나 터미널의 이어 하기 목록에 보이지 않았다. 이제 각 CLI의 기본 저장소를 함께 쓴다. 로그인 정보는 계정별로 따로 둔다.

- Claude: 세션 기록과 관련 폴더를 `~/.claude`로 모은다.
- Codex: 세션 파일과 이어 하기 색인을 `~/.codex`로 모은다. 세션 파일 복사가 끝난 계정만 공용 색인으로 넘어간다. Orca 계정 폴더의 원본은 옮기지 않고 사본으로 가져온다.
- agy: 대화 기록을 `~/.gemini`로 모은다. 대화 목록 DB는 agy가 대화 기록에서 다시 만드는 것을 확인해 내용을 합치지 않고 연결만 바꾼다.
- OpenCode는 바꾸지 않았다. 로그인 정보와 세션이 한 DB에 있어 계정 분리를 지키려면 별도 동기화가 필요하다. 다음 과제로 남긴다.
- 이미 쌓인 기록은 지우지 않는다. 겹치는 파일은 백업 폴더에 남긴다. 옮기는 작업은 그 프로필을 쓰는 프로그램이 꺼져 있을 때만 하고, 쓰는 중이면 다음 확인 때 다시 시도한다.
- 옮기는 순간 같은 계정으로 다른 프로그램이 막 켜지면, 그 프로그램이 쓴 최신 내용이 백업 폴더에 남을 수 있다.

## 모바일: 퀵터널을 예비 경로에서 뺌

- 휴대폰은 Krill 릴레이로만 연결한다. 직접 설정한 Named Tunnel과 Tailscale 모드는 그대로 쓸 수 있다.
- 릴레이에 연결하지 못하거나 이 버전의 모바일 웹앱이 아직 배포되지 않았으면, 퀵터널로 넘어가지 않고 그 이유를 바로 보여 준다. 릴레이는 뒤에서 계속 재시도한다.
- 이전 버전이 띄워 둔 퀵터널은 krilld가 정리한다.
