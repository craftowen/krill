Krill 0.2.12 improves session recovery, startup input, remote workspace isolation, and update safety.

- **Startup and clipboard input:** preserve edits made while the saved workspace is loading, keep terminal input and multiline paste confirmations in order, and reject delayed input when its destination changes.
- **Session recovery:** preserve published session IDs when panes are hidden and restore terminal readers after an interrupted daemon upgrade. On Windows, bound blocked input writes and report uncertain delivery without automatically replaying it.
- **Remote workspaces:** keep file editors, terminal file menus, Changes, Search, Checks, and History from falling back to a local repository when a remote connection is unavailable. Preserve unsaved remote buffers when saving is unavailable, and keep reopened files on their original host. Local-only actions remain unavailable for remote workspaces. Improve SSH connection teardown, installation paths containing spaces, and cancelled peer connections.
- **Windows projects and automation:** accept Windows and Unix paths according to the remote host, keep a shell open after creating or cloning a Windows project, and run scheduled prechecks through Git for Windows.
- **Updates and search:** refuse rollback without a valid journal, restore only complete backups, preserve recovery information when a backup is missing, keep CRLF edits intact, and align fallback regular-expression search with ripgrep.
- **CLI and mobile:** protect local cleanup commands from remote scope mistakes, preserve offline orchestration locking and delivery outcomes, close doctor probe processes, retain mobile pairing fragments, and reject stale quick actions after a host switch.
- **Packaging:** correct Homebrew executable links, annotated-tag checks, Windows release source checkout, shader rebuild inputs, and documentation links.
