Krill 0.2.1 brings together the desktop, remote-host, mobile, and account-continuity work completed after the first public beta.

- **Remote provider accounts:** choose a connected host in account settings and manage that host's profiles, usage, and auto-switch settings. The status-bar account popup switches profiles on the focused host, and account handoffs reconnect the corresponding remote panes. Login commands run on the selected host.
- **Chat and attachments:** refined message and tool cards support expansion and file navigation. Clipboard images and files can be delivered to remote sessions through their host connection or SSH, with failures surfaced before sending a path.
- **Workspace presentation:** remote repository icon discovery and host-aware project filters improve sidebar consistency. The dashboard shortcut is now Cmd+Shift+L, with Escape closing the dashboard.
- **Agent continuity:** conversation identity and transcript discovery better handle descendant processes, Antigravity conversation files, and late hook metadata during account transitions.
- **Mobile pairing and installation:** the Mobile page restores or creates a pairing offer as needed. Home Screen installation guidance covers iOS and Android, while successful connections and interrupted transports no longer consume the authentication-failure budget.
- **Terminal selection:** Option/Alt-drag selects rectangular column ranges while existing word, line, and Shift-click selections retain their behavior.
- **Installers:** macOS and Windows terminal installers display staged progress in interactive terminals while preserving plain output for captured or piped runs.
