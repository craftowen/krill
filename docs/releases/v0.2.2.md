Krill 0.2.2 improves mobile terminal scrolling and worktree creation from nested folders.

- **Mobile terminal gestures:** scrolling on a live TUI follows its mouse or alternate-screen cursor mode in both directions. Shift can route a gesture to local history, and touch momentum stops when another gesture, mode change, or hidden view takes over.
- **History stability:** alternate-screen applications keep shell history out of the live view. History refresh preserves unchanged rows and the current reading position, and returning to the bottom restores live output.
- **Host-aware worktree creation:** creating a worktree from a nested working directory resolves the containing workspace on the selected host while preserving exact membership checks for existing worktrees.
