Krill 0.2.6 combines the latest workspace, Windows, and mobile improvements.

- **Workspace sidebar:** show connected remote hosts consistently, reconcile Windows path aliases without losing session and project metadata, and keep workspace selection and status updates aligned.
- **Windows processes and Git:** improve child-process startup, foreground process discovery, and path handling for Git changes and worktree removal.
- **Windows installation:** rerunning the installer preserves existing app binaries and user files while repairing shortcut and PATH integration. Incomplete installations remain untouched and report the missing component.
- **Mobile terminal:** add a Quick Commands button to the tab bar for managing and running saved commands, and provide a persistent live-input row with photo attachment. Preserve split panes, clipboard access, IME handling, and reading-position anchors. Improve history preloading after hidden views become visible, queue refreshes during in-flight loads, and preserve pinch and selection anchors.
- **Mobile assets:** retain the existing compressed-asset budget and touch-target checks while removing redundant runtime CSS comments; license notices remain included.
- **Agent status and hooks:** recognize permission and question prompts more consistently, keep active tool invocations from becoming idle prematurely, synchronize installed Claude hooks into account profiles, and launch only receipt-backed Codex hook events while preserving per-account trust verification.
- **Build verification:** reuse immutable vendored dependencies in macOS CI with content and configuration checks, and isolate simulated holder PIDs from real operating-system processes.
