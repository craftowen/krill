Krill 0.2.9 refreshes the desktop chat view, adds session-specific account switching, and improves file editing and usage details.

- **Desktop chat:** use a centered transcript and composer, expand tool details, copy code, and return to the latest message. Keep your reading position and draft when switching between Chat, Term, and tabs. Multiline prompts use terminal paste support and preserve the draft when delivery needs review.
- **Accounts and usage:** switch the selected session to another account without changing the default account or other sessions. Improve handoff recovery, provider identification, custom agent profiles, and host-scoped account controls. Show reset-credit expiry dates when providers supply them and label missing expiry information explicitly.
- **Files and editing:** add syntax highlighting and HTML preview actions. Keep browser and reveal actions on the file's local or remote host, and preserve terminal focus while file tabs reload.
- **Session and workspace details:** add a sticky last-prompt bar, recent prompt timeline, and structured session hover cards. Improve task-title consistency and preserve saved local tabs during incomplete daemon snapshots.
- **Windows and mobile:** reopen the existing Windows tray app on a second launch, refine hook setup and credential handling, and improve mobile direct-input controls and connection recovery.
- **Usage metrics and error reports:** add bounded delivery queues and CLI flush commands. Usage metrics are enabled by default and can be disabled with `krill telemetry disable` or `DO_NOT_TRACK=1`; error reporting remains a separate, default-off setting. Neither schema includes prompts, terminal output, commands, project paths, or account details. Receiver provisioning remains separate from this desktop release; local queueing does not establish successful delivery. See [usage metrics](https://github.com/craftowen/krill/blob/v0.2.9/services/telemetry/CLIENT.md).
