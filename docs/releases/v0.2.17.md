# Krill v0.2.17

Optional error reports now have a production receiver at `errors.krill.page`. Existing supported clients use the same wire contract and can resume delivery when reporting is enabled.

The receiver validates the fixed metadata schema, stores acknowledged reports durably, deduplicates retries, limits admission and storage, and expires reports after 30 days. Event and aggregate queries require a separate administrator credential.

Error reporting keeps its separate, default-off consent. Enable **Settings → Resources → Send error reports**, or run `krill errors enable`. Reports exclude prompts, terminal output, credentials, user paths, and raw logs.
