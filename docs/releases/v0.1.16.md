# Krill v0.1.16 릴리스 노트

## 새 기능

- **프로젝트 끌어다 놓기**: 사이드바의 프로젝트(저장소) 머리줄을 끌어다 다른 프로젝트 위에 놓으면 순서가 바뀝니다. 바꾼 순서는 앱을 다시 켜도 유지됩니다(내 Mac 프로젝트).
- **원격 호스트 정리**
  - 별칭·IP·Orca 가져오기로 따로 등록된 같은 기기(사용자·주소·포트가 같은 기기)는 사이드바에 한 번만 보이고, 연결도 하나만 엽니다.
  - 설정 > SSH에 '같은 기기 중복 등록' 카드가 생겼습니다. '중복 정리'를 두 번 누르면 먼저 등록한 항목만 남기고 지웁니다. `~/.ssh/config` 가져오기와 Orca 가져오기는 이미 등록된 기기를 다시 넣지 않습니다.
  - 연결되지 않았고 세션도 없는 원격 호스트는 사이드바 맨 아래 '연결 안 된 호스트 N개' 한 줄로 묶입니다. 누르면 펼쳐집니다. 짝지은 기기(iroh)는 묶지 않습니다.
  - 끊긴 호스트에는 이유가 보입니다(꺼져 있음·인증 거부·원격 로그인 꺼짐·Krill 없음).
  - 30초가량 계속 연결에 실패한 호스트는 1분 간격으로만 다시 시도합니다. '다시 연결'을 누르면 바로 시도합니다.
- **터미널 글자 크기**: ⌘+스크롤로 글자 크기를 바꿉니다.
- **Diff 검토**: 파일별 '확인됨' 표시와 검토 주석 전체 삭제 버튼이 생겼습니다.
- **붙여넣기**: 스크린샷 클립보드를 실제 이미지 파일로 저장합니다(TIFF는 PNG로 변환). 평문 URL에 마우스를 올리면 미리보기가 보입니다.
- **워크트리**: `.worktreeinclude`의 glob 패턴으로 파일을 복사합니다. 서브모듈이 초기화된 깨끗한 워크트리도 삭제됩니다.
- **오케스트레이션 CLI**: `worker-start --preamble full|minimal|none`, `ask --question-id`로 같은 질문 다시 기다리기.
- **모바일**: Cloudflare Tunnel이 첫 연결 방식으로 먼저 보입니다. 데몬이 다시 시작돼도 cloudflared를 다시 이어받아 같은 주소를 유지합니다. Named Tunnel을 지원합니다. 앱으로 돌아왔을 때 응답 없는 연결을 감지해 다시 붙고, 터미널 연결을 미리 열어 둡니다. Shift 보조키가 생겼습니다.

## 개선

- **새 버전 확인 주기**: 앱이 업데이트를 4시간마다만 확인해, 앱을 켜 둔 동안 나온 릴리스가 늦게 보였습니다. 이제 30분마다 확인합니다. 이번 v0.1.16은 설정의 '업데이트 확인'이나 앱 재시작으로 바로 받을 수 있습니다.
- 칸을 닫으면 맞닿은 이웃 칸으로 포커스가 옮겨 갑니다.
- 터미널 경로·URL 링크가 한·중·일 조사와 전각 괄호 앞에서 끊깁니다.
- 서브에이전트나 외부 프로세스의 훅 때문에 브랜치 이름이 자동으로 바뀌지 않습니다.
- Codex 프로필 홈 경로를 짧게 바꿔(`~/.krill/p/codex/<짧은 키>`) 소켓 경로 길이 제한에 걸리지 않게 했습니다. 예전 경로는 옮겨 옵니다. Orca 이관은 `~/.orca/codex-homes`도 찾습니다.

## 알려진 제한

- 모바일 릴레이(Cloudflare DO) 서버는 아직 배포하지 않았습니다. Tunnel 모드는 지금처럼 Tunnel로 연결됩니다.
- 폰 실기(LTE·iOS 키보드)는 확인하지 않았습니다.
