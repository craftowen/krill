# Krill v0.1.17 릴리스 노트

## 새 기능

- **모바일 홈 화면 설치**: 모바일 웹 앱을 홈 화면 앱으로 설치할 수 있습니다. 페어링 직후 안내가 뜨고, 설정 → Home Screen에서도 설치할 수 있습니다.
  - Android(Chrome): 설치 창이 뜹니다. 설치된 앱은 브라우저의 페어링을 그대로 씁니다.
  - iPhone·iPad(Safari): 공유 → 홈 화면에 추가 안내가 뜹니다. 홈 화면 앱은 5분짜리 일회용 페어링 티켓으로 'iPhone / iPad (Home Screen)'이라는 별도 기기로 등록되며, 데스크톱에서 따로 해제할 수 있습니다. 5분 안에 홈 화면 앱을 처음 열어야 합니다.
  - 기기 비밀값은 URL 쿼리·manifest·HTTP 요청 어디에도 실리지 않습니다. 일회용 티켓만 서버로 전송되지 않는 URL 조각(`#` 뒤)으로 넘깁니다(헤드리스 Chrome에서 요청·프레임 256개 검사). iPhone·Android 실기는 확인하지 않았습니다.
- **모바일 릴레이(Cloudflare)**: Tunnel 모드에서 Cloudflare 중계 서버를 거쳐 연결할 수 있습니다. 중계 서버는 암호화된 내용만 전달하며, 암호화 연결의 일회성 값(챌린지)도 Mac의 Krill이 직접 만들어 중계 서버가 세션을 재생할 수 없습니다.

## 개선

- **상태바 계정 전환**: Claude·Codex 등 사용량 팝업에서 계정이 한 줄씩 보이고, ✓가 이름 옆에 붙습니다. 줄을 누르면 바로 전환됩니다. 상태 배지는 로그인 필요·한도 도달처럼 정상이 아닐 때만 보입니다. 팝업을 열 때마다 활성 계정을 다시 받아, 다른 곳에서 바꾼 전환이 늦게 보이지 않습니다.
- **사이드바 '기본' 워크트리 맨 위**: 프로젝트마다 '기본' 워크트리(저장소 본 체크아웃)가 정렬 방식과 관계없이 맨 위에 옵니다. 그 아래로 고정한 워크트리, 나머지 순입니다.
- **사이드바 세션 들여쓰기**: 워크트리 카드 아래 세션 줄이 카드 제목 아래에서 시작해, 어느 워크트리의 세션인지 보입니다. 자식 워크트리의 세션은 한 단계 더 들어갑니다.
- **상단 탭 여백**: 탭 안쪽 여백·최소 폭(120px)·탭 사이 구분선을 넣어 탭 경계가 보입니다.
- 상태바 SSH 메뉴도 같은 기기 중복 등록을 한 번만 보입니다.

## 알려진 제한

- iPhone·Android 실기(홈 화면 설치, LTE)는 확인하지 않았습니다.
- iPhone에서 홈 화면에 추가한 뒤 5분 안에 열지 않으면 티켓이 만료돼, 아이콘을 지우고 다시 추가해야 합니다.
