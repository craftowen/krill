# Krill v0.1.11 릴리스 노트

## 새 기능

- **모바일 외부 접속 고정 주소(OWE-906)**: 터널 모드 QR이 이제 고정 주소 `https://krill-mobile.pages.dev/m/<버전 해시>/`를 엽니다. 앱 코드는 Cloudflare Pages에서 받고, 데이터는 Mac의 Quick Tunnel로 종단간 암호화해 주고받습니다.
  - Mac 재부팅이나 터널 재시작으로 터널 주소가 바뀌어도 폰은 랑데부(`/r/<id>`)에서 새 주소를 찾아 다시 연결합니다. 재스캔·재페어링이 필요 없고, 홈 화면 아이콘도 유지됩니다.
  - 페어링 비밀값은 URL fragment에서만 읽고 바로 주소창에서 지웁니다. 터널 주소는 `*.trycloudflare.com` 형식만 받습니다.
- **cloudflared 자동 확보**: 터널 모드에서 `cloudflared`가 없으면 공식 릴리스를 받아 검증한 뒤 사용합니다.

## 개선

- v0.1.8 릴리스 노트의 원격 자동 설치 설명을 정정했습니다. 앱에서 바로 설치·업데이트하는 것은 macOS 원격만이고, Linux 원격은 `install-linux.sh`로 설치한 뒤 연결합니다.

## 알려진 제한

- 고정 주소 모드는 Cloudflare Pages에 해당 버전의 PWA가 올라가 있어야 합니다. 준비되지 않았으면 QR은 기존처럼 터널 주소로 강등됩니다.
- 그 밖에는 v0.1.10과 같습니다.
