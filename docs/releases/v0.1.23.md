# Krill v0.1.23 릴리스 노트

## 모바일

- 홈 화면에서 최근 세션을 이어 열고, 등록된 여러 데스크톱과 세션 없는 워크스페이스도 탐색합니다.
- 연결·인증·요청의 대기 시간을 제한하고, 재접속과 호스트 전환 뒤 늦게 도착한 응답을 무시합니다. 실패한 입력은 자동 재전송하지 않습니다.
- 채팅 초안·질문 카드·선택·스크롤을 화면 갱신과 이동 중 보존합니다. 이전 대화를 읽거나 최신 대화로 돌아갈 수 있습니다.
- 과거 질문·권한 요청은 현재 터미널에서 확인합니다. 이미지 준비, 여러 줄 붙여넣기, 입력 모드와 화면 크기 전환을 보강했습니다.
- 언어를 바꾸면 현재 설정 화면도 즉시 번역합니다. 한국어·영어, 화면 배율, QR 스캔·연결 안내와 계정·Git·오케스트레이션 화면을 개선했습니다.
- 신규 연결은 릴레이 또는 Tailscale을 사용합니다. 기존 LAN 설정은 기기 인증정보를 유지하며 릴레이로 이행합니다.
- iOS 홈 화면 설치에는 별도 기기를 등록하는 일회용 페어링 링크를 사용합니다.

## 데스크톱과 계정

- 사이드바·설정·파일 탐색기·파일 저장·클립보드 작업을 백그라운드에서 처리하고, 늦은 응답이 새 상태를 덮어쓰지 않게 했습니다.
- 계정별 Antigravity·OpenCode 로그인, Orca 계정 이관, 제공자별 상세 사용량과 계정 전환 중 입력 보존을 반영했습니다.
- 프로젝트 표시 이름·아이콘·배지, 알림 음소거, 세션 상태 설명과 설정 화면을 개선했습니다.
- SSH 호스트와 원격 Krill 연결 설정을 별도 페이지로 구분합니다.
- 칸·탭을 명시적으로 닫을 때만 해당 세션을 종료합니다. 앱·창 종료와 업데이트에서는 세션을 보존합니다.
- 탭 표시·이동·일괄 닫기를 현재 워크스페이스에 한정하고, 다른 워크스페이스의 세션과 분할 상태를 보존합니다.
- 터미널 행 렌더 계획과 포트 감지 결과를 재사용하고, 보이지 않는 커서의 깜박임을 중단합니다. 과거 이력을 읽는 동안에도 입력 요청을 처리하며 입력 대기열 크기를 제한합니다.
- 실행 중 계정 전환과 새 세션의 제공자별 프로필 적용을 보강했습니다.

## 오케스트레이션

- 작업자 retain 상태와 CLI, 게이트 옵션 검증, 내장 스킬 안내를 추가했습니다.
- 기존 메시지 직렬화 순서를 유지하며, 데몬에 요청을 보낸 뒤 응답이 끊기면 디스크 변경을 중복 실행하지 않습니다.
- CLI 하위 명령의 도움말을 연결 전에 표시하고, 전송 텍스트와 옵션 값에 포함된 도움말 문자열을 구분합니다.

## 설치

- Windows 설치 스크립트의 다운로드·체크섬 검사·기존 설치 보존을 보강했습니다.
- macOS는 ad-hoc 서명이며 공증된 Developer ID 배포판은 아닙니다. Windows의 미검증 실기 범위는 기존 문서와 같습니다.
