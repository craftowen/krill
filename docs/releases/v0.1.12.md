# Krill v0.1.12 릴리스 노트

## 버그 수정

- **원격 탭을 보고 있으면 업데이트가 롤백되던 문제**: 업데이트 후 새 앱의 정상 기동 판정(30초)이 화면에 보이는 터미널 칸의 연결을 기다렸습니다. 그래서 꺼진 원격 호스트나 느린 SSH 탭이 보이면 판정 기한을 넘겨 이전 버전으로 롤백되고, 자동 업데이트가 같은 시도를 반복했습니다(맥미니-설 실기: 0.1.10→0.1.11이 3회 연속 롤백). 이제 정상 기동 판정은 로컬 칸 연결로만 하고, 원격 칸만 보이면 기다리지 않습니다.

## 알려진 제한

- v0.1.11과 같습니다.
