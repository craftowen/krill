- **Mobile workspace creation:** create a Git worktree from the workspace list with project, branch source, agent, and host selection. Review the setup script before starting, and use suggested names for new worktrees.
- **Mobile navigation and terminals:** search and select project filters, remove filter chips with the keyboard, and select live terminal text without incoming output moving the selection. Photo actions follow the terminal input mode.
- **Antigravity sessions:** isolated account profiles receive the installed Krill hook bundle while retaining custom hooks. Session titles use conversation annotations or the first user prompt, and attachment markers are removed from generated titles and branch names.
- **Account identity:** imported Claude accounts match stored profiles by UUID or email. Removing an account hides matching imported aliases, and adding it again restores visibility.
- **GitHub support controls:** the desktop landing page and settings can open the project on GitHub and reflect star status when GitHub CLI authentication is available. The support prompt is limited to once per version.
