Krill 0.2.3 adds remote file workflows and saved mobile commands, with steadier mobile navigation and history.

- **Remote files:** browse, search, open, edit and save files on the selected remote host. File tabs distinguish identical paths on different hosts, saves detect changed files, and remote localhost links with an explicit port open through a local tunnel that closes after inactivity.
- **Remote worktrees:** newly created worktrees appear immediately with their parent lineage. Parent selection and deletion use the selected remote host, and daemon sidebar caches refresh after worktree changes.
- **Mobile quick commands:** edit saved commands in Settings and insert them into the terminal or chat composer. Insertion leaves sending under your control, and concurrent desktop settings saves preserve unrelated fields.
- **Mobile continuity:** conversation refreshes retain existing message nodes and reading position; navigation keeps the tablet sidebar and pending session layout stable.
- **Copy cleanup:** copied TUI text removes bullet decorations and joins wrapped lines within each item while preserving separate items.
- **Connection checks:** publishing verifies the mobile connection when the local connection verifier is available.
