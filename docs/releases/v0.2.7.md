Krill 0.2.7 brings together the latest desktop workspace, Windows startup, and mobile command improvements.

- **Session startup:** retry safe daemon handshakes during restarts and retain uncertain create/resume outcomes without automatically replaying requests that could create duplicate sessions.
- **Workspace navigation:** search connected hosts in Jump, distinguish matching session IDs on different computers, retain project ordering and visuals, and reveal the focused session without repeatedly undoing a manually folded card.
- **Notifications and usage:** keep automatic reconnects, background account refreshes, and successful account switches quiet while retaining actionable errors and input recovery. Improve usage refresh coordination and transcript lookup.
- **Windows integration:** reopen an existing app for the same state directory, preserve isolated runs, keep background helper processes hidden, and improve device names, account paths, pull request tools, and mobile connection guidance.
- **Mobile Quick Commands:** discover installed skills and custom commands for the selected session, search their descriptions, and add them to saved commands while preserving the existing settings writer and explicit send behavior.
- **Mobile input:** retain live input text through delayed acknowledgments and viewport changes in a reserved input row. Keep Hangul composition, local backspace handling, clipboard access, modifier keys, history anchors, and split-session ownership.
- **Prompt titles:** recognize orchestration and handoff wrappers so workspace titles use the task itself. Preserve the mobile asset budget and license notices while removing redundant runtime comments.

- **Mobile accessibility:** preserve focus across nested dialogs, show errors inside open sheets, support arrow-key tab navigation, and accept Unicode command names up to the character limit. Keep live input readable as text size grows.

- **Native file watching:** update the stable notification backend so failed macOS stream startup is surfaced instead of silently leaving an inactive watcher.
- **Terminal scrollback and file links:** preserve hot scrollback across `CSI 3 J` redraws and background demotion, advance progressive upward scrolling smoothly across history sources, and open wrapped or remote image and file paths directly from terminal output with cached hover lookups.
- **Desktop and mobile UI polish:** restore Mobile page back-navigation state, localize the Chat/Term view toggle, remove duplicate sidebar and asset entries, and unify empty chat prompts across desktop and mobile.
