Mobile error diagnostics, desktop chat view persistence, and documentation updates:
- Mobile technical error diagnostics: mobile web and local mobile clients now report minimized technical failure categories and sanitized error codes automatically by default, with an opt-out toggle in Mobile Settings -> Advanced -> Error Reporting and automatic suppression when Do Not Track (`DNT: 1`) or Global Privacy Control (`Sec-GPC: 1`) is enabled.
- Receiver privacy enforcement: the error intake service rejects requests carrying `DNT: 1` or `Sec-GPC: 1` headers and strips browser URL, user-agent, and viewport metadata from automatic browser error payloads.
- Desktop chat view persistence: per-pane chat view mode is now persisted in layout state across app restarts and updates while keeping prompt submission acknowledgements bound to the active chat pane.
- Documentation: updated the English and Korean README introductions, benchmark scope notes, and native UI theme descriptions.
