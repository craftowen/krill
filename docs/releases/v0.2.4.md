Krill 0.2.4 adds an in-app automations workspace and a richer artifact library, with fixes for session history and workspace cleanup.

- **Automations:** create and edit schedules from a dedicated page, use starter templates, inspect run history and output, and trigger runs manually. Editing existing schedules preserves options outside the simplified editor and rejects duplicate IDs.
- **Artifacts:** search the library, inspect artifact details, open local sources, and delete shared artifacts from the app.
- **Sidebar and workspaces:** restore project icons from repository metadata, refresh branch labels, repair stale workspace paths, and remove completed process rows without mixing sessions from different hosts.
- **Session continuity:** preserve inherited history when resuming sessions, retain stable history snapshots across concurrent recording, and prevent explicitly closed sessions from reappearing as resumable sessions. Account login failures provide a path back to the terminal.
- **Mobile:** retain host data through connection and storage revisions, with clearer handling of device renaming and disconnect failures.
- **Windows:** handle already-exited processes during terminal close and check Job Object process counts when completion messages lag.
