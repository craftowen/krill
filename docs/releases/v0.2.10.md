Krill 0.2.10 improves Windows terminal paste, tab restoration, and account usage recovery.

- **Windows paste:** Ctrl+V pastes clipboard text into the terminal, including links and Unicode text. Ctrl+Shift+V remains available.
- **Tabs and restoration:** restore late-arriving sessions even when the sidebar has no selection, preserve local tabs during incomplete daemon snapshots, and refresh hidden tab titles when the task changes.
- **Usage recovery:** try the next Claude credential source when an earlier source is malformed. Keep recent successful usage values during a failed refresh, mark them stale, and preserve their original update time.
- **Usage status:** show the existing status when quota data is unavailable, and discard pending usage results when direct usage has been disabled.
