# Krill v0.1.25 릴리스 노트

- 하단 사용량 표기를 `0% 1h 31m · 92% 1d 19h`처럼 퍼센트와 남은 리셋 시간만으로 간소화했습니다. 앱 언어와 무관하게 `m`·`h`·`d` 단위를 쓰며, 좁은 창에서도 최대 사용률 창의 남은 시간을 표시합니다.
- 사이드바에서 카드 안 세션에 카드 여백을 다시 더하던 중복 들여쓰기를 제거했습니다. 호스트·프로젝트 들여쓰기도 줄여 세션 이름 공간을 확보하고 계보 깊이는 유지합니다.
- 원격 Krill 설정에 이 Mac에서 연결한 원격 Mac 목록과 현재 연결 상태를 표시합니다. 다른 기기의 수신 접근 권한 목록과 구분하며 등록·상태 변경을 주기적으로 갱신합니다.
