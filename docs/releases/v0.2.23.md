Windows agent console encoding fixes and README benchmark update:
- Windows agents on non-UTF-8 consoles: the agent launcher now switches the console output code page first and still starts the agent (with its Ctrl+C guard) when the UTF-8 switch fails, reporting the failure on the session screen and continuing at the inherited code page instead of refusing to launch.
- CP949 regression coverage: native Windows tests force a hidden console to code page 949 and require UTF-8 bytes from a `-NoProfile` PowerShell grandchild through both the agent launcher and the default PowerShell bootstrap, covering the Korean Windows failure where agy rejected tool output as invalid UTF-8.
- Documentation: published the 2026-10-28 re-measurement against Orca in the English and Korean READMEs.
