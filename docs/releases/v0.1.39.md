- **Project navigation:** the sidebar groups work by project, keeps one active workspace selection, and expands running agent sessions from their workspace. New terminals use the selected project or worktree.
- **Desktop responsiveness:** background history and capture work uses bounded caches, layout saves are coalesced, and the renderer avoids waiting for a drawable on the UI thread. Diff switches keep the previous content until the replacement arrives; progress labels reserve their space.
- **Mobile workflows:** keyboard and scroll handling, chat recovery, saved desktop connections, local drafts, and update preparation have been revised. Photo attachment sits beside the command input.
- **Account usage:** provider-specific usage periods and refresh states are clearer. Automatic requests are spaced out, rate limits retain the last successful value as stale, and an explicit refresh can request new data immediately.
- **Session creation:** ordinary repository discovery avoids extra Git processes, the project picker offers connected hosts, and early agent exits produce a readable startup message. The sidebar's bottom new-session menu opens upward so keyboard selection is not taken over by the pointer.
- **Compatibility and maintenance:** new usage-refresh messages have a separate negotiated feature and preserve the existing account-cancellation message encoding. Windows setup guidance uses Windows commands, Windows agents start without PowerShell parsing their arguments, and ctutils is updated for RUSTSEC-2026-0385.
