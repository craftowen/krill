# Krill v0.1.22 릴리스 노트

## 새 기능

- **Orca 열린 에이전트 세션 이관 (`sessions` 도메인)**: `krill import orca`와 앱의 Orca 가져오기 모달에 '열린 에이전트 세션' 항목이 추가되었습니다. Orca의 열린 탭에 연결된 에이전트 세션을 모아 각 워크트리에서 이어 띄우며, 이미 이관한 세션은 다시 띄우지 않습니다.
- **탭·칸 닫기 시 데몬 세션 종료**: 칸·탭 닫기(단축키·× 버튼·일괄 닫기)를 실행하면 다른 칸이나 창에 같은 세션이 열려 있지 않을 때 데몬 세션도 함께 종료합니다. 앱 종료·창 닫기·크래시 경로에서는 기존처럼 세션이 그대로 보존됩니다.
- **사이드바 프로젝트 아이콘·배지 색 표시 (`Orca RepoIcon`)**: 저장소·폴더 헤더와 표시 > 프로젝트 필터 목록에 프로젝트 아이콘(`projects.toml`의 `repo_icon` → 저장소 내 파비콘·로고 → `package.json` `homepage` 파비콘 → GitHub 소유자 아바타)과 배지 색을 표시합니다. Orca 이관 시 `repoIcon`도 함께 옮깁니다.

## 개선 및 버그 수정

- **사용 중 계정 프로필 별칭 경로 보호**: 심볼릭 링크(별칭) 경로로 열린 세션이 참조하는 계정 프로필도 사용 중 삭제와 고아 정리에서 보호합니다.
- **계정 로그인 실패·취소 경로 검증 강화**: 새 계정 로그인 실행 실패 시 부분 프로필 정리와 재로그인 취소·실패 시 기존 프로필 보존 회귀 테스트를 강화했습니다.
- **릴리스·하네스 자동화**: `release.yml`에 무료 네이티브 러너(`ubuntu-22.04`, `ubuntu-22.04-arm`) 기반 Linux `x86_64`·`aarch64` 빌드 및 데몬 `SIGKILL` 생존 스모크 검증 잡을 추가하고, 저장소 `pre-push` 훅(`scripts/install-hooks.sh`)과 `.claude` 가드 훅을 포함했습니다.
