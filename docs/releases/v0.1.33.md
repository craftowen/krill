# Krill v0.1.33 릴리스 노트

v0.1.32 이후 변경은 다음과 같다.

- 아티팩트 공유: 설정 > 아티팩트 페이지에서 공개 공유를 켜면 `.html`·`.md` 파일 머리의 공유 버튼으로 공개 링크를 만들고, 목록에서 링크 복사·열기·삭제를 할 수 있습니다. 공개 공유는 기본 꺼짐이며, CLI `krill artifacts share|update|status --json`도 같은 설정을 따릅니다.
- 워크스페이스의 탭을 모두 닫으면 다른 워크스페이스로 넘어가지 않고 그 워크스페이스의 빈 화면으로 남습니다.
- 원격 Mac과 짝짓기할 때 연결할 Mac 이름을 직접 정할 수 있습니다.
- Finder로 실행한 앱에서도 Codex 훅 설치가 로그인 셸 PATH로 `codex`를 찾습니다.

- 모바일 채팅에서 요청과 답변을 구분해 표시하고, 세션 행에 에이전트 아이콘을 보여줍니다. 프로젝트 필터는 여러 개를 고를 수 있습니다.
- 모바일 전체화면 TUI에서 위로 끌면 이전 내용으로 스크롤하고, 세션 화면의 뒤로가기는 프로젝트 세션 목록으로 갑니다.
- 페어링 링크나 홈 화면 앱을 처음 열면 확인 화면 없이 바로 짝짓기합니다.
- 기본 소켓이 아닌 krilld(테스트·수동 실행)는 모바일 게이트웨이를 켜지 않아, 실사용 모바일 연결이 몇 분마다 끊기던 문제를 고쳤습니다.
