# v0.2.28

- The app no longer drops its daemon connection because of a single slow reply. On a heavily loaded PC one late heartbeat used to raise a disconnect alert, show "reconnecting" in the sidebar and pause account polling even though the daemon was healthy. Two replies in a row must now be missed before the daemon counts as unresponsive.
- When creating or resuming a session fails, or takes more than 2 seconds, the app now writes it to its log (error kind, whether it was an agent, whether it was a resume, elapsed time). Failures used to leave no trace.
- Release validation now runs the real-browser mobile suites against the release binaries, so a mobile terminal that cannot render can no longer ship unnoticed.
