# v0.2.31

- When an agent CLI exits and its tab drops back to the login shell, Krill now still recognizes that the agent has exited. `krill wait` returns again, an orchestration worker that dies right after starting is reported as "exited during startup" instead of waiting for the startup timeout, and the sidebar shows the agent as finished. The running agent under the shell is tracked as the session's foreground program again.
