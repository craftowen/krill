# Krill v0.1.32 릴리스 노트

v0.1.31 이후 변경은 다음과 같다.

- macOS가 화면 버퍼를 늦게 돌려줄 때 입력까지 멈추던 문제를 고쳤습니다. 이전에는 버퍼를 받을 때까지 메인 스레드가 무기한 기다려 0.5~3초 동안 키 입력이 반응하지 않을 수 있었습니다. 이제는 그 프레임을 건너뛰고 다음 화면 갱신 때 다시 그리며, 입력은 계속 처리합니다.
- 0.5초 이상 화면이 멈추면 앱 로그에 기록합니다(이전 기준 5초). Krill 창이 활성일 때만 기록하고, 1.5초 넘게 이어지는 멈춤의 스택 샘플은 10분에 한 번만 로컬에 남깁니다.
