# Krill v0.1.31 릴리스 노트

v0.1.30 이후 변경은 다음과 같다.

- 상태바 사용량 팝업의 "사용량 초기화"로 Claude 주간 세션 리셋과 프로모션 리셋 grant도 소진할 수 있습니다. Codex banked reset과 같은 리셋 크레딧 칸에 남은 횟수를 표시합니다.
- 계정 프로필 프로비저닝을 기본으로 켭니다. 새 계정 프로필이 `~/.claude`의 스킬·프로젝트·플러그인을 링크로 공유합니다. 설정에서 끈 값은 그대로 유지합니다.
- 로그인 전에 임시 이름으로 만든 Claude 프로필 폴더를 이메일이 확인되면 이메일 이름 폴더로 옮깁니다. 키체인 자격증명을 먼저 복사·검증한 뒤 옮기며, 세션이 쓰는 폴더와 사용자 지정 폴더는 건드리지 않습니다.
- 계정 전환은 연결된 대화 ID가 확인될 때만 진행하고, 새 계정 프로필의 대화 기록이 같은 대화인지 확인한 뒤에 원래 세션을 종료합니다. 확인에 실패하면 새 프로세스를 닫고 원래 세션을 유지합니다.
- 이벤트 이름이 없는 훅은 이미 연결된 대화 ID를 바꾸지 못합니다.
- 계정 전환 실패 알림은 같은 실패에 한 번만 표시합니다.

- 사이드바 렌더 때마다 반복하던 워크트리 계보 계산을 목록을 다시 만들 때 한 번만 해, 워크트리가 많을 때의 렌더 비용을 줄였습니다.
- 사이드바 상세 카드에서 워크트리 아래 에이전트 목록을 하나의 패널로 이어 그립니다.
- 탭과 칸 헤더의 YOLO 배지, 사용량의 경고·위험 색을 없앴습니다.
