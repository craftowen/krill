Krill 0.2.11 improves clipboard input, initial session connections, and usage diagnostics.

- **Clipboard input:** preserve text pasted before the first terminal connection completes, keep following typing in order, and reject delayed clipboard results after the destination changes.
- **Pending sessions:** keep an initial session connection alive when switching tabs until its result is saved, then release hidden screen connections. This avoids cancelling the continuation before the created session is recorded.
- **Usage diagnostics:** show whether quota refresh failed while reading credentials, preparing the request, connecting, receiving an HTTP response, or parsing the response. Retain recent successful readings and their original update time during refresh failures.
- **Account details:** display usage failure details in account cards and preserve the popover layout when selecting accounts.

These diagnostics help identify account-specific failures; they do not guarantee that every provider authentication or usage request succeeds.
