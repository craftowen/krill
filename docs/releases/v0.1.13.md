# Krill v0.1.13 릴리스 노트

## 새 기능

- **원격 호스트에 상대 Mac의 프로젝트 표시**: 원격 호스트에 연결하면 사이드바 호스트 그룹에 그 Mac에 등록된 프로젝트가 모두 보입니다. 지금까지는 세션이 떠 있는 저장소만 보였습니다. 보관한 프로젝트와 다른 호스트용 프로젝트는 빠집니다. 목록은 원격 Mac의 krilld가 보내므로 원격 Mac도 v0.1.13으로 업데이트해야 보입니다.

## 모바일 속도 개선

이 맥 안에서 직결(loopback)·release 빌드·세션 6개로 잰 값입니다. 폰 LTE 구간은 재지 않았습니다.

- **세션 목록 갱신**: 폰이 2.5초마다 받는 세션 목록 응답이 290~300ms에서 캐시 적중 시 2~5ms, 캐시가 없을 때 126~149ms로 줄었습니다. 저장소가 아닌 폴더의 세션은 git 조회를 건너뛰고, 같은 폴더는 한 번만 조회하며, 폴더별로 병렬 조회한 결과를 5초 동안 재사용합니다. 승인·프롬프트 전송 뒤에는 목록 갱신을 기다리지 않고 버튼이 바로 풀립니다. 탭이 숨겨지면 갱신을 멈춥니다.
- **연결**: WS 연결 수립이 p50 24~33ms에서 0.8ms로, 인증이 7~8ms에서 0.2~0.3ms로 줄었습니다(연결 수락 대기 50ms 폴링 제거, 재접속 인증마다 하던 디스크 동기 저장 제거). 인증 뒤 첫 메시지를 서버 응답을 기다리지 않고 함께 보내 연결마다 왕복이 1번 줄었습니다.
- **터미널 화면**: 바뀐 행만 화면 주기에 한 번 그립니다. 200×60에서 한 줄 바뀔 때 그리기가 15~20ms에서 0.2~0.3ms로 줄었습니다(헤드리스 Chrome, 배율 3). 폰으로 보내는 화면 갱신은 초당 최대 약 30번으로 묶습니다(쉬던 화면의 첫 변경은 바로 보냅니다).
- **git 대기**: git 하위 프로세스 출력을 10ms·5ms마다 확인하던 것을 출력이 오면 바로 깨어나도록 바꿨습니다. 데스크톱 앱의 git 변경 표시도 같은 경로를 씁니다.

## 개선

- **SSH 접속 사용자 누락 안내**: Tailscale로 찾은 Mac을 한 번에 추가하면 주소에 사용자가 없어, 이 PC 계정 이름으로 접속합니다. 상대 Mac 계정 이름이 다르면 인증이 거부되는데, 이제 그 원인과 '편집'에서 주소를 `계정@주소`로 고치는 방법을 함께 알려 줍니다.

## 버그 수정

- **탭이 많을 때 활성 탭이 가려지던 문제**: `⌘1`~`⌘9`, 새 탭, 앱 재시작 복원처럼 클릭 없이 활성 탭이 바뀌면 탭 줄이 따라 스크롤하지 않아 활성 탭이 오른쪽 넘침 영역에 숨었습니다(맥미니-설 실기 화면 캡처로 확인). 이제 활성 탭이 항상 탭 줄 안에 보입니다. 탭 줄을 직접 스크롤한 뒤에는 그 위치를 유지합니다.
- **새 Quick Tunnel QR을 바로 스캔하면 Cloudflare 530 오류로 열리지 않던 문제**: 퀵 터널은 첫 정상 응답 뒤에도 약 30초 동안 요청 일부가 530이었습니다(단독 실측 11회). 고정 주소 PWA에 현재 버전이 올라가 있으면 지금처럼 첫 정상 응답에서 QR을 내고(PWA가 재시도로 견딥니다), 아니면 터널이 안정될 때까지 기다렸다가 QR을 냅니다. 이 경우 QR이 나오기까지 약 37~39초 걸립니다(실측 3회, 이후 530 0/50).
- **모바일 연결이 응답 없이 멈추던 문제**: 인증 뒤 첫 요청이 5초 넘게 없거나 데몬 쪽 처리가 먼저 끝나면 연결이 닫히지도 응답하지도 않았습니다. 이제 연결이 닫히고 PWA가 다시 접속합니다.
- 처음 페어링할 때 연결이 한 번 실패하면 다시 시도하지 않던 문제를 고쳤습니다.

## 알려진 제한

- v0.1.11과 같습니다. 폰 실기(LTE·iOS 키보드)는 확인하지 않았습니다.
