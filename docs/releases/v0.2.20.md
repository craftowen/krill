Mobile UI and UX improvements across Home, Workspaces, Sessions, Source Control, and Settings:
- Connection and pairing: the connection status banner now sits below page headers so navigation and header actions remain reachable while reconnecting. QR photo and live scan errors are surfaced and translated inside the scanner dialog, landscape phone viewports use a compact scanner layout, and the pairing URL sheet supports submitting with Enter. Active desktops can also be removed directly from the Home screen.
- Workspaces and worktree creation: the worktree creation sheet waits for explicit focus before expanding branch suggestions, preserves in-flight worktree creation and setup script prompts if the sheet is closed early, keeps the Cancel button visible alongside the primary action, and spaces the floating create button and bottom notices away from the workspace list.
- Sessions, split panes, and quick actions: offline quick-action edits are retained across reconnects until synced, quick actions can be reordered with up/down controls, and terminal keybar customization can be reset to defaults in Settings. Split-terminal headers track the active pane state and reconnect an active secondary pane without restarting the primary terminal, while stacked phone landscape splits hide the inactive command dock to preserve terminal viewport height.
- Source control and Korean localization: Git diff views explain oversized diffs and out-of-scope or unchanged files without offering a misleading retry action for size limits, light-mode muted text contrast is improved, and missing Korean translations across connection diagnostics, workspaces, and settings are completed.
