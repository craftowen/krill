# Krill v0.1.30 릴리스 노트

v0.1.29 이후 변경은 다음과 같다.

- 링크·재연결·자리 비움·멈춤·조치 필요·붙여넣기 알림을 우하단 토스트 하나로 모읍니다. 보안 확인 알림도 같은 자리에 표시합니다.
- 터미널의 파일 경로를 우클릭하면 Krill에서 열기, 기본 앱으로 열기, Finder에서 보기, 경로 복사를 고를 수 있습니다. 공백·따옴표·마크다운 안의 경로도 인식하고, 실제로 있는 파일만 후보로 고릅니다.
- 사이드바 카드 목록은 스냅샷이 갱신돼도 스크롤 위치와 행을 유지합니다. 상태 스피너는 사이드바 전체를 다시 그리지 않고 제자리에서만 돕니다.
- 팝오버에 계정별 창별 사용량과 리셋 시간을 표시하고, 좁은 창에서는 줄바꿈합니다.
- 데몬 세션과 탭을 맞출 때 기존 탭의 순서·분할·포커스를 유지하고, 종료 중인 세션은 다시 열지 않습니다.
- Mac 원격 연결 해제에 확인 단계와 실패 안내를 추가했습니다.

- 계정 수동·자동 전환이 다음 할당량 갱신을 기다리지 않고 바로 실행됩니다. 여러 세션은 동시에 몰리지 않게 나눠 다시 시작하고, 이어서 하던 작업을 계속하도록 안내합니다.
- 계정 전환이 실패하면 새 계정으로 보내려던 입력을 원래 계정에 보내지 않고 버리며, "계정 전환이 실패해 보내지 않은 입력" 알림을 띄웁니다. 실패 원인도 구체적으로 표시합니다.
- 데몬이 전환 도중 종료돼도 진행 중이던 모든 전환을 복구해 마무리합니다.
- 이벤트 이름이 없는 훅이 이미 묶인 대화 ID를 바꾸지 못하게 했습니다.
- 사용량 조회는 PATH를 검색하지 않고 OS 기본 curl만 씁니다.

- 원격 호스트 연결 세대를 구분해, 같은 소켓으로 다시 등록한 연결과 폐기된 연결을 구별하고 핸드셰이크 도중 해제된 연결을 버립니다.
- 모바일 PWA에서 저장된 데스크톱 제거, 데스크톱 선택 시트, 다른 탭에서 연결을 제거하면 즉시 끊는 동작을 추가했습니다.
- 한글 IME 조합 글자가 숨은 커서를 쓰는 TUI(Claude Code 등)에서 화면 위쪽에 따로 그려지던 문제를 고쳤습니다.
- 남아 있던 Minikrill 이름을 Krill로 바꿨습니다(스킬·훅·설정 경로·로컬 코드 서명 인증서). 기존 서명 키체인과 업데이트 서명 키는 그대로 이어서 씁니다.
