# Krill v0.1.29 릴리스 노트

v0.1.26·v0.1.27·v0.1.28 태그는 내부 후보로 끝나고, 이 릴리스에 합쳤다. v0.1.25 이후 변경은 다음과 같다.

- Codex 요금제 한도에 걸리면 상태바 사용량 팝업의 "사용량 초기화"에서 banked reset 크레딧으로 5시간·7일 창을 초기화할 수 있습니다. 두 번 눌러 확인하는 방식이며, 터미널에서는 `krill account consume-reset codex <계정>`으로 같은 동작을 합니다.
- 설정의 계정 화면에서 OpenCode Go API 키를 저장할 수 있습니다. 저장하면 `/connect` 키나 `OPENCODE_API_KEY`보다 먼저 써서 상태바 사용량을 조회합니다.
- 프로젝트 추가 대화상자에서 실행 위치(내 Mac·연결된 원격 호스트)를 고를 수 있습니다. 원격 호스트를 고르면 호스트 경로를 직접 입력해 폴더 열기·복제·새 프로젝트를 만듭니다.
- pi 에이전트를 스킬·오케스트레이션 대상으로 지원합니다. 같은 저장소의 연결 워크트리는 사이드바에서 본 워크트리 자식으로 묶어 접을 수 있고, 설정 행마다 (?) 도움말과 설명 문구를 다듬었습니다.
- 모바일 홈·계정 화면을 다듬고 PC 연결이 끊기지 않게 했으며, 데스크톱 사이드바 순서·아이콘을 모바일 스냅샷에도 반영합니다. 모바일 스냅샷 RPC 워커 스택을 키워 대시보드 조회 중 데몬이 중단되던 문제를 고쳤습니다.
- 설정 검색에서 띄어쓰기로 나뉜 여러 단어를 같은 항목 안에서 모두 만족하면 찾습니다(예: "worktree cleanup" → 리소스 탭).

- 지원 플랫폼을 Apple Silicon(M 시리즈) Mac과 Windows x64로 정리했습니다. Intel Mac·Linux의 CI 빌드·설치·패키징·게시 자산을 제거했습니다.
- 연결된 원격 호스트를 사이드바에서 직접 연결 해제할 수 있으며, 수동으로 끊은 호스트는 다시 연결할 때까지 자동 재접속하지 않습니다. 연결 상태의 RTT 숫자를 제거해 주기적인 표시 변화를 줄였습니다.
- 워크트리 포트 배지는 3개까지만 표시하고 나머지는 개수로 접습니다. 설정·온보딩 안내와 접근성 라벨을 보강하고, 업데이트 채널 불일치를 화면에 표시합니다.
- 터미널별 핫 스크롤백 상한을 적용하고, 한글 IME 회귀 검사와 수동 QA 문서를 추가했습니다.

- 선택한 워크스페이스의 호스트·경로에서 새 탭과 에이전트를 실행합니다. 분할 터미널 헤더는 작은 오버레이로 표시합니다.
- SSH 원격 터미널에 클립보드 이미지·파일을 올려 원격 경로를 붙여넣습니다. 전송의 종료·시간 제한과 파일 충돌 방지를 보완했습니다. SSH 전송 경로가 없는 링크 원격에는 로컬 파일 경로를 보내지 않습니다.

- 계정 전환 완료 정보를 디스크에 저장한 뒤 공개하도록 바꿔, 직후 데몬을 강제 종료했을 때 전환 기록을 잃을 수 있던 경합을 수정했습니다.
