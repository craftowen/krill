# Krill 0.2.15

- 모바일 채팅에 명령·스킬·파일 찾기, 실행 중 모델 변경 확인, 이전 대화 불러오기를 추가했습니다.
- 모바일 터미널의 한글 조합 표시와 붙여넣기를 개선했습니다.
- 아티팩트 공유 기한을 새 링크 기본값과 개별 링크별로 설정할 수 있습니다. 기존 링크의 만료일은 이번 전환으로 바뀌지 않습니다.
- 운영 릴레이에 Google 계정 로그인을 추가했습니다. 로컬 터미널과 직접 연결의 기기 인증은 별도로 유지됩니다.

## 기존 릴레이 사용자의 로그인 전환

데스크톱을 업데이트한 뒤 설정 → 모바일 또는 `krill mobile login`에서 로그인하고, 휴대폰에서도 같은 Google 계정으로 로그인하세요. 기존 페어링 기록과 실행 중 터미널은 삭제되지 않습니다. 이전 익명 릴레이는 원래 릴레이 키를 증명한 호스트가 로그인할 때 해당 계정에 귀속됩니다.

새 릴레이 연결·재연결에는 로그인이 필요합니다. 이미 성립한 직접 터널 연결은 유지될 수 있습니다. 예전 모바일 화면에서 로그인 안내가 나타나지 않으면 https://krill-mobile.pages.dev/auth 에서 로그인한 뒤 다시 열거나, 업데이트한 데스크톱의 새 QR로 연결하세요. 기존 연결이 다른 Google 계정에 귀속된 경우에는 그 계정으로 로그인해야 합니다.
