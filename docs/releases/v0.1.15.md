# Krill v0.1.15 릴리스 노트

## 개선

- **사이드바 단계 들여쓰기**: 호스트 > 프로젝트 > 워크트리 > 세션이 단계마다 오른쪽으로 들어가 구분됩니다. 지금까지는 프로젝트와 그 아래 워크트리 행이 같은 위치에서 시작해 어디에 속한 행인지 알기 어려웠습니다. 원격 호스트를 등록해 호스트 머리줄이 보일 때는 프로젝트 행도 한 단계 들어갑니다. 상세·촘촘한 카드 레이아웃 모두 같습니다.

## 버그 수정

- **모바일에서 한글이 자모로 깨지던 문제**: 모바일 터미널의 직접 입력에서 한글을 치면 '한글' 대신 'ㅎㅏㄴㄱㅡㄹ'이 들어갔습니다. 입력할 때마다 숨은 입력칸을 비워, 조합 중인 글자를 바꿔 쓰는 키보드(iOS 방식)의 수정이 반영되지 않았기 때문입니다. 이제 바뀐 부분만 보내 조합된 글자가 그대로 들어갑니다(헤드리스 Chrome에서 iOS 방식 두 가지와 조합 이벤트 방식 확인, iPhone·Android 실기는 미확인). 이전 출력 화면에서 한글처럼 2칸을 쓰는 글자의 폭과, 분리된 자모(NFD)로 나온 글자의 표시도 맞췄습니다.
- **사이드바 워크트리 수가 부풀던 문제**: Orca에서 가져온 워크트리 목록에는 이미 지운 워크트리도 남아 있어, 사이드바에 없는 워크트리가 보이고 저장소 옆 숫자가 실제보다 컸습니다(실측 예: 실제 git 워크트리 37개인 저장소가 92로 표시). 이제 디스크에 있는 워크트리만 보입니다.
- **`top` 같은 setuid 프로그램 세션이 닫히지 않던 문제**: 세션 첫 명령이 root 권한으로 도는 프로그램이면 탭을 닫거나 `krill kill`을 해도 끝나지 않았습니다. 이제 2초 안에 끝납니다(격리 데몬 실측).

## 알려진 제한

- v0.1.14와 같습니다. 폰 실기(LTE·iOS 키보드)는 확인하지 않았습니다.
