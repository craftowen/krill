Krill 0.2.0 is the first public beta. It brings the features developed during private use together with the latest workspace, agent, mobile, and remote-connection improvements.

- **Artifacts:** publish HTML and Markdown files as shareable links, update the same link, and manage shared files from the sidebar. Public sharing requires enabling it in settings; links expire 30 days after their last publication or update.
- **Automations:** manage scheduled work, templates, run history, session reuse, and isolated worktree base branches from the app and CLI.
- **Workspace navigation:** sidebar grouping, saved ordering, background worktree creation, and base-branch selection are refined. Split panes can be selected by recency, and large lists render a bounded window.
- **Worker orchestration:** configured launches, model and effort options, per-session run selection, linked retries, durable mailbox delivery receipts, and explicit worker retention and release controls improve coordination. Borrowed or reassigned terminal sessions are preserved.
- **Agent continuity:** worktree creation and partial-delete recovery use ownership evidence. Antigravity identity recovery and first-prompt titles, initial prompt delivery, Pi hooks, and account-switch recovery notifications are improved. Hook identity takes precedence over stored launch hints.
- **Session views:** choose Chat or Terminal as the default in settings. Explicit per-session choices survive navigation and account handoff.
- **Mobile workspaces:** device-specific workspace preferences and tablet split panes accompany live terminal input and chat controls. Viewport changes, keyboard transitions, and rotation preserve pane selection, terminal mounts, input focus, and scroll position.
- **Remote hosts:** remote connections tolerate a missed probe while keeping paths scoped to their host. Updated Windows hosts can connect through the SSH stdio bridge when socket forwarding is unavailable.
- **Computer controls (experimental):** bounded screenshot capture, coordinate mapping, and incremental observations accompany worker delivery, verification, and cleanup controls. The isolated native worker and MCP path remain opt-in experiments.
