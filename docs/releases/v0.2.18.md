Mobile connections keep the relay available alongside the Tailscale backup. Saved connections prefer the relay, retain direct connection credentials across daemon restarts, and explain when a private-network QR must be opened directly. Google account recovery preserves pending pairing and provides an explicit path to switch accounts when a desktop belongs to a different account.

Windows daemon upgrades preserve active ConPTY holders and defer incompatible holder upgrades while sessions are running. The holder drains queued listener notifications before handling daemon exit, while retaining duplicate-daemon detection and rollback behavior.

Projects can choose a custom directory for new worktrees. Account switching also preserves the permission mode of agents launched directly from a shell.

The release includes the completed CI tool installer update. Work still in progress in other worktrees is excluded.
