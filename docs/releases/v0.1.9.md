# Krill v0.1.9 릴리스 노트

v0.1.8을 실제 Mac(맥미니-설)에 설치해 화면을 조작하며 검증하다 찾은 문제를 고친 버전입니다.

## 버그 수정

- **사이드바에 새 워크트리가 저장소로 한 번 더 보이던 문제**: `⌘N`으로 만든 워크트리가 원래 저장소 아래와 별도의 "저장소" 그룹에 두 번 보이던 문제를 고쳤습니다. 이제 linked 워크트리는 주 저장소로 등록되고, v0.1.8이 이미 잘못 등록한 항목도 주 저장소 그룹 안으로 합쳐집니다.
- **설치본에서 늘 "설정 점검 필요"가 뜨던 문제**: 앱 번들에서는 `krill-holder`·`krilld`가 `Contents/Helpers`에 있는데 빠른 점검이 `krill` 옆만 찾아, 정상 설치인데도 상태바에 "설정 점검 필요"가 떠 있었습니다. 같은 이유로 건너뛰던 바이너리 버전 비교도 이제 실제로 합니다. 점검 실패 문구도 한국어로 나옵니다.
- **터널 모드에서 cloudflared가 없을 때 오류 문구**: `krill mobile pair --tunnel`이 "entity not found"만 보이던 것을 cloudflared 설치 안내로 바꿨습니다.
- **스크린리더 탭 이름**: 파일 탭에 에이전트 상태("알 수 없음")가 붙어 읽히던 것과 끝 공백을 정리했습니다.

## 알려진 제한

- v0.1.8과 같습니다(Apple Silicon 전용 번들·공증 없음, Linux `KillUserProcesses`, Quick Tunnel 주소 변경, Windows는 소스만 포함).
- 터널 모드는 여전히 `cloudflared`가 PATH에 있어야 합니다. cloudflared 자동 확보·고정 주소 PWA는 Cloudflare Pages·Worker 배포 뒤 다음 버전에 들어갑니다.
