## Changes

- Add a tablet workspace sidebar and two independent terminal panes, with saved split direction and keyboard focus that follows the active pane.
- Improve mobile project and session navigation, terminal history scrolling, host-scoped drafts, offline snapshots, and bounded chat/storage caches.
- Open the artifact library directly inside the main window, with search, refresh, pagination, and publishing from supported open files.
- Choose the first-launch language from the operating system, retain saved language preferences, and provide English and Korean getting-started guides and macOS permission descriptions.
- Move Metal drawable acquisition off the UI thread, retain display-link recovery, and reduce repeated screen composition, Git discovery, and background UI work.
- Harden account-switch recovery, preserve input while a handoff is unresolved, and provide an explicit way to continue the original session after a failed switch.
- Consolidate outstanding workspace and branch changes while retaining the current Apple Silicon macOS and Windows x64 release scope.

## 변경 사항

- 태블릿 작업 공간 사이드바와 독립된 터미널 2개 분할, 분할 방향 저장, 활성 칸 입력 포커스를 추가했습니다.
- 모바일 프로젝트·세션 탐색, 터미널 과거 출력 스크롤, 호스트별 입력 초안, 오프라인 스냅샷과 채팅·저장소 캐시 제한을 개선했습니다.
- 아티팩트 목록을 메인 창에서 바로 열고 검색·새로고침·추가 페이지 조회와 열린 파일 공유를 사용할 수 있습니다.
- 첫 실행 언어를 운영체제 설정에서 선택하고 기존 언어 선택을 유지합니다. 영어·한국어 첫 실행 가이드와 macOS 권한 설명을 제공합니다.
- Metal 드로어블 획득을 UI 스레드 밖으로 옮기고 디스플레이 링크 복구를 유지했습니다. 화면 조합·Git 탐색·백그라운드 UI의 반복 작업을 줄였습니다.
- 계정 전환이 확정되기 전 입력을 보류하고, 전환 실패 시 원본 세션으로 명시적으로 돌아갈 수 있게 했습니다.
