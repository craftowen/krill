# Krill v0.1.21 릴리스 노트

## 새 기능

- **터미널 테마**: 설정 → 터미널에서 내장 테마 30종 중 고를 수 있습니다. 다크 모드와 라이트 모드 테마를 따로 정할 수 있고(기본 켜짐), Ghostty·Warp 테마 파일을 가져올 수 있습니다.
- **Diff를 화면 가운데에**: 변경 파일 diff 본문이 오른쪽 패널 대신 화면 가운데에 열립니다. 닫기 버튼·Esc·⌘W로 닫고, 열려 있는 동안 키 입력은 뒤의 터미널로 가지 않습니다.
- **모바일 새 세션 시트**: 세션 화면의 "+"가 설정된 에이전트 목록과 Terminal을 보여 주는 시트를 엽니다.
- **모바일 홈 화면 설치 카드**: 홈에 설치 카드가 뜨고, 연결이 끊기면 Reconnect, 인증이 거부되면 Re-pair 버튼이 나옵니다. 앱 아이콘이 크릴 마크로 바뀌었습니다.

## 개선

- **모바일 기본 보기 터미널**: 세션은 터미널로 열리고, 폰에서는 Fit to Phone이 자동으로 켜집니다. 키보드가 열려도 터미널 행 수가 유지됩니다.
- **모바일 속도**: 미리 연 터미널 연결을 재사용하고, 바뀐 것이 없으면 화면 데이터를 다시 보내지 않습니다. 첫 연결 대기 시간을 300초로 늘렸습니다.
- **채팅**: agy 대화 기록으로 채팅 대상을 찾고, 질문 카드 답이 화면에 보이는 커서 위치에서 시작합니다.
- **Jump 팔레트**: ↑↓로 움직이면 목록이 고른 줄을 따라 스크롤됩니다.
- **스킬 설치**: orchestration·computer-use 스킬을 항상 `mk-` 이름으로 설치합니다. 예전 버전이 깔아 둔 Krill 사본만 정리하고 Orca 스킬은 건드리지 않습니다.

## 버그 수정

- **`krill orchestration` 조회 실패**: 실행 중인 run이 없으면 `run-list`·`worker-list`·`gate-list`·`run-current`가 `bad body: Hit the end of buffer`로 실패하던 문제를 고쳤습니다. 데몬이 새 버전으로 바뀌어야 고쳐집니다.

## 알려진 제한

- 모바일 변경은 iPhone 14 에뮬레이션으로 확인했고, iPhone·Android 실기는 확인하지 않았습니다.
- Windows zip은 코드 서명(Authenticode)이 없어 처음 실행할 때 SmartScreen 경고가 뜹니다. 한글 IME·Windows 10/11 실기 QA는 아직입니다.
