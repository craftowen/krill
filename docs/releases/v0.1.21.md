# Krill v0.1.21 릴리스 노트

## 새 기능

- **Krill 브랜드 아이덴티티**: 무채색이던 화면 크롬이 심해 남색 틴트로 바뀌었습니다(상태색·탭·git 색은 그대로). 세션이 보존되고 있다는 표시는 경고색 대신 `preserve` 톤으로 보이고, 작업 중 스피너는 3분절 아크입니다. 사이드바 머리와 빈 작업 공간에 크릴 마크가 들어갔고, 상태바 세션 수 옆에 세션 상태를 보여 주는 떼 미터가 생겼습니다.
- **터미널 테마 31종**: 설정 → 터미널에서 내장 테마 31종(Krill Deep + Orca 내장 30종) 중 고를 수 있습니다. 다크 모드와 라이트 모드 테마를 따로 정할 수 있고(기본 켜짐), Ghostty·Warp 테마 파일을 가져올 수 있습니다.
  - 다크 기본은 Krill 고유 **Krill Deep**(배경 `#10131b`, 코랄 커서, ANSI 16색은 Ghostty Default Style Dark와 같음)입니다. 이전 기본 색은 `Ghostty Default Style Dark`로 계속 고를 수 있습니다.
  - 앱이 테마를 보내기 전에 데몬이 답하는 터미널 색 질의(OSC 10/11/12/4) 기본값도 Krill Deep입니다.
- **데몬 재연결 배너**: 데몬 연결이 끊기면 경고 대신 `preserve` 톤 배너로 "세션은 krill-holder가 보관" 중임을 알리고, 다시 연결돼 세션 목록을 받으면 다시 연결한 세션 수를 잠깐 보여 줍니다. 분리된 세션 목록의 실행 중 행에도 같은 톤의 점이 붙습니다.
- **자리 비운 사이 요약**: 앱을 다시 켜면 꺼져 있던 동안 완료된 세션과 확인이 필요한 세션 수를 한 줄로 보여 줍니다(hook으로 상태를 아는 세션만 셉니다. 1분 미만이거나 0개면 표시하지 않습니다).
- **Diff를 화면 가운데에**: 변경 파일 diff 본문이 오른쪽 패널 대신 화면 가운데에 열립니다. 닫기 버튼·Esc·⌘W로 닫고, 열려 있는 동안 키 입력은 뒤의 터미널로 가지 않습니다.
- **Windows 배포**: PowerShell 설치 스크립트 `https://krill.page/install.ps1`로 설치합니다(macOS는 기존대로 `curl -fsSL https://krill.page/install.sh | bash`). 관리자 권한 없이 `%LOCALAPPDATA%\Programs\Krill`에 설치되고 시작 메뉴 바로 가기가 생깁니다. 릴리스에는 `Krill-0.1.21-windows-x64.zip`도 올리며, 자동 업데이트는 Windows 전용 매니페스트 `latest-windows.json`(macOS와 같은 Ed25519 서명)을 봅니다.
- **모바일 릴레이 우선 연결**: 외부 접속(Tunnel) 모드는 암호화 릴레이가 붙는 즉시 QR을 내고, 퀵터널(cloudflared)은 릴레이 연결이 실패하거나 이 버전의 모바일 웹 앱이 고정 주소에 아직 없을 때만 띄웁니다. 설정 → 모바일은 연결을 기다리는 동안에도 다른 연결 방식 선택·기기 관리·다른 탭 이동이 되고, 1초가 넘으면 "모바일 연결 준비 중…"을 보여 줍니다. 기기를 모두 해제하면 기다리던 페어링도 바로 끝납니다.
- **모바일 새 세션 시트**: 세션 화면의 "+"가 설정된 에이전트 목록과 Terminal을 보여 주는 시트를 엽니다.
- **모바일 홈 화면 설치 카드**: 홈에 설치 카드가 뜨고, 연결이 끊기면 Reconnect, 인증이 거부되면 Re-pair 버튼이 나옵니다.

## 개선

- **알림음·아이콘**: macOS 알림음이 시스템 경고음 대신 Krill 2음 차임입니다(소리 설정이 꺼져 있으면 기존처럼 무음, 터미널 벨은 그대로). DMG 창에 남색 배경과 Applications 안내가 들어갔고, Windows exe·트레이 아이콘도 Krill 마크입니다.
- **모바일 브랜드**: 모바일 화면이 심해 남색 색상을 쓰고, 홈 안내 문구가 "Connect to Krill on your Mac"입니다. 설치 아이콘은 코랄 크릴 PNG(192·512·마스커블·apple-touch)입니다.
- **모바일 기본 보기 터미널**: 세션은 터미널로 열리고, 폰에서는 Fit to Phone이 자동으로 켜집니다. 키보드가 열려도 터미널 행 수가 유지됩니다.
- **모바일 속도**: 미리 연 터미널 연결을 재사용하고, 바뀐 것이 없으면 화면 데이터를 다시 보내지 않습니다. 모바일 연결의 첫 요청 대기 시간을 300초로 늘렸습니다.
- **모바일 Chat 버튼**: 에이전트가 아닌 셸 세션에서는 Chat 전환 버튼을 숨깁니다. 셸에서 누르면 "Waiting for agent hook…"에서 멈췄습니다.
- **모바일 재연결 안내**: 데스크톱에 닿지 못해 재시도할 때는 배너에 "Can’t reach desktop. Retrying…"만 쓰고 같은 오류 토스트를 반복하지 않습니다.
- **세션 이름**: 칸을 열지 않은 세션도 사이드바에 터미널 제목으로 이름이 보이고, 제목 앞의 에이전트 상태 글리프(✳·스피너 등)는 뗍니다. 서브에이전트·팀메이트 hook 이벤트는 상위 세션 상태를 바꾸지 않습니다.
- **워크트리 이름 변경**: 사이드바 워크트리 카드의 인라인 이름 변경에 저장(✓)·취소(✕) 버튼이 생겼습니다.
- **채팅**: agy 대화 기록으로 채팅 대상을 찾고, 질문 카드 답이 화면에 보이는 커서 위치에서 시작합니다.
- **Jump 팔레트**: ↑↓로 움직이면 목록이 고른 줄을 따라 스크롤됩니다.
- **스킬 설치**: Orca와 이름이 겹치는 orchestration·computer-use 스킬을 항상 `krill-orchestration`·`krill-computer-use` 이름으로 설치합니다. 예전 버전이 맨 이름이나 `mk-` 이름에 깔아 둔 Krill 사본만 정리하고, Orca 스킬·다른 스킬·심링크는 건드리지 않습니다.

## 버그 수정

- **`krill orchestration` 조회 실패**: 실행 중인 run이 없으면 `run-list`·`worker-list`·`gate-list`·`run-current`가 `bad body: Hit the end of buffer`로 실패하던 문제를 고쳤습니다. 데몬이 새 버전으로 바뀌어야 고쳐집니다.
- **터미널 첫 스크롤**: 이전 기록을 받아 온 직후 처음 아래로 스크롤하면 화면이 움직이지 않던 문제를 고쳤습니다.
- **모바일 헤더 사라짐**: 입력할 때 숨은 입력창이 화면을 밀어 올려 헤더(뒤로 버튼)가 사라지던 문제를 고쳤습니다.

## 알려진 제한

- Windows 앱은 코드 서명(Authenticode)이 없습니다. PowerShell 설치 명령으로는 보통 SmartScreen 경고가 뜨지 않지만 실기에서는 확인하지 않았습니다. Windows 10/11 실기 한글 IME QA는 하지 않았습니다.
- 모바일 변경은 헤드리스 Chrome(iPhone 14 에뮬레이션)으로만 확인했고, iPhone·Android 실기(키보드, 홈 화면 앱 모드)는 확인하지 않았습니다.
