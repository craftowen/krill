# v0.2.27

- Mobile terminals render again. v0.2.25 and v0.2.26 showed "Trailing screen data" instead of the terminal because the phone could not read the cursor byte the desktop daemon added to screen updates.
- The log no longer fills with repeated identical lines: the same event is kept 3 times per minute, with the number of suppressed repeats reported afterwards. A display-link failure used to write 25,433 lines in a day and push every rotated log out.
- The daemon no longer crashes when it runs `git` (a crash in the child process after `fork`), retries a failing scheduler with a growing delay instead of once a second, and uses a smaller compression window per session so ten terminals stay within the 60 MB daemon budget.
- The app retries starting incoming access after a slow boot, and display-link restarts back off to 30 seconds while no display is active.
