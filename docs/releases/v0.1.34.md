# Krill v0.1.34 릴리스 노트

v0.1.33 이후 변경은 다음과 같다.

**호환성 주의:** 옛 이름(minikrill) 호환 코드를 지웠습니다. 업데이트 서명 형식과 원격 연결·페어링 프로토콜 이름이 바뀌어, v0.1.33 이하 앱은 이 버전을 자동 업데이트로 받지 못하고 직접 내려받아 설치해야 합니다. 원격 Mac·기기는 양쪽 모두 v0.1.34 이상이어야 연결되며, 옛 번들(`dev.minikrill.app`)·`~/.config/minikrill`에서 자동으로 옮겨 오는 기능도 없어졌습니다.

- 입력은 받는데 화면만 멈추던 문제를 고쳤습니다. 커서는 정상이고 비치볼도 뜨지 않지만, 다른 앱에 갔다 오기 전까지 타이핑·클릭·애니메이션이 화면에 반영되지 않던 증상입니다.
  - 화면 버퍼가 화면에 올라갔다는 신호가 0.25초 넘게 오지 않으면 신호를 기다리지 않고 다시 그립니다.
  - 버퍼 대기는 최대 1초로 제한합니다.
  - 창이 보이는데 화면 갱신 신호가 1초 넘게 끊기면 신호를 다시 연결하고, 그래도 끊겨 있으면 새로 만듭니다.
- 화면 버퍼 대기, 화면 갱신 신호 끊김, 그리기 쪽 오류를 앱 로그에 남깁니다. 지금까지는 어디에도 기록되지 않았습니다.
- 설정 > 일반에서 앱 테마를 고를 수 있습니다: 다크 4종(심해·심연·조수·발광), 라이트 2종(기본·종이).
- 사이드바의 에이전트 대시보드 아래에 아티팩트 항목을 추가했습니다.
- 앱을 시작하면 설치된 에이전트(claude·codex·opencode·cursor-agent·agy)에 상태 감지 훅을 기본으로 설치합니다. 설정 > 에이전트에서 끌 수 있습니다.
- 원격 Mac 목록에서 바로 이름을 바꿀 수 있습니다. 기기 '짝짓기' 표기를 '페어링'으로 통일했습니다.
- Orca가 감지한 계정을 Krill 목록에서 숨길 수 있습니다(Orca 파일은 건드리지 않음).
- 하단바 사용량을 5시간·주간 막대 쌍으로 보여주고, 좁은 창에서는 리셋 시간을 가장 큰 단위로 줄입니다.
- 프로젝트 아이콘에 JPEG를 지원하고, 받지 못한 아이콘 URL은 간격을 두고 다시 시도합니다.
- 모바일 PWA 에셋이 배포되지 않았어도 릴레이 연결을 유지하며, 게시 전에 에셋 배포를 확인합니다.
- 화면이 멈췄을 때 원인을 가를 수 있도록, 이상이 있었던 1초마다 프레임 결과를 앱 로그에 남깁니다. 남기는 값은 렌더·건너뜀·화면 표시·드롭 수, 가장 늦게 표시된 프레임의 지연, 화면 버퍼 크기 변경입니다.
- 오케스트레이션 워커를 시작할 때 자식 워크트리를 함께 만듭니다. 기준 브랜치는 부모 브랜치이고, 로컬 작업 경로를 시작 전에 확인합니다. 원격 자식 워크트리 요청은 SSH 연결 전에 거부하고, 워커 세션 생성에 실패하면 작업을 실패로 정산합니다.
- krill 스킬 설명에 아티팩트(공개 공유 링크) 트리거를 추가했습니다.
