Krill 0.2.5 brings the latest workspace and mobile improvements on top of 0.2.4.

- **Folder workspaces:** create a workspace and terminal in a registered folder without requiring Git. Setup scripts still require approval, and mobile-created sessions keep their chosen title.
- **Conversation history:** keep multi-part transcript records together, preserve stable paging boundaries, and handle appends and replacements without losing or duplicating conversation items.
- **Mobile workspaces:** use display names and saved session titles consistently, keep workspace counts aligned with the catalog, and remove orphaned ended-session state. Device-specific filters and sorting remain local to each phone.
- **Mobile terminal:** extend hardware and on-screen modifier handling, avoid overlapping hot-history rows, and retain reading position while output arrives.
- **Mobile UI:** expand translated interface and error text, improve semantic Markdown lists and tables, and show when Git output has been capped.
- **Home Screen installation:** renew nearly expired pairing offers while keeping a still-valid installation link stable across repeated offers.
- **Embedded assets:** losslessly re-encode icons to keep the complete PWA within the existing 200 KiB compressed-asset budget.
