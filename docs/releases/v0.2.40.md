# Krill v0.2.40

- Claude 계정 프로필이 기본 `~/.claude`의 설정, 플러그인, 스킬, 명령, 에이전트, 규칙, 키 설정과 대화 기록을 그대로 참조합니다. 계정마다 따로 두는 것은 로그인과 런타임 상태뿐입니다.
- 기존 프로필은 세션을 끄지 않아도 자동으로 옮겨집니다. 프로필에만 있던 플러그인과 프롬프트 기록은 기본 폴더로 합치고, 이전 내용은 `~/.claude/projects-merged-backup`에 보존합니다.
- 대화 기록을 공유하는 계정끼리 세션을 재개할 때 활성 계정을 유지합니다.
- `krill account provisioning off`는 이제 Claude에 적용되지 않습니다. Codex와 Antigravity의 동작은 그대로입니다.
