Krill 0.2.8 improves terminal history, mobile controls, workspace previews, and account switching.

- **Terminal history and selection:** preserve scrollback through consecutive screen clears, load history requested during connection startup, and correct wrapped-line selection and grid updates. Retain the compact parked-history representation introduced in 0.2.7.
- **Mobile controls:** offer touch choices for recognized terminal questions, improve scrolling when the live grid is shorter than the viewport, and prevent browser zoom from competing with terminal gestures. Remove the duplicate Quick Commands tab action while keeping saved quick actions in the input dock and settings.
- **Mobile session continuity:** remove exited tabs, move to a live terminal or the workspace list when the selected session ends, and preserve split connections, scroll positions, and the saved PC display mode through rotation and reconnection.
- **Workspace previews:** show the last user prompt in session hover cards and improve session titles and previews across tabs and the sidebar. Refine provider account lists and local/remote switching controls, and keep dashboard animation updates local to status icons.
- **Windows and file links:** improve CLI PATH discovery, credential decoding, and Codex conversation lookup. Open terminal image and file links with the correct local or remote handler.
- **Optional error reporting:** add separate, default-off consent in Settings and `krill errors` commands. Reports use a fixed metadata schema that excludes prompts, terminal output, credentials, and raw logs. Delivery requires the separately provisioned receiver; local queueing and retry limits apply while it is unavailable. See [error reporting](https://github.com/craftowen/krill/blob/v0.2.8/docs/agents/error-reporting.md).
