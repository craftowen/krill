# v0.2.24

- Windows terminal input tracks AltGr key releases across modifier and focus changes. Native image paths retain Windows spelling, foreground shells use their own paste policy, and rejected file pastes show a message.
- File-path paste refuses unsafe PowerShell Unicode quote delimiters. Code search finds native `rg.exe` on Windows, and mobile workspace labels recognize Windows paths.
- Explorer transfers use handles and atomic creation or rename to preserve existing destinations, reject symlink and reparse traversal, and report observed namespace conflicts. Tab menu keyboard navigation stays within enabled menu items.
- Hidden sessions defer repeated grid cache trims during output bursts, reducing allocator churn.
- OpenCode SQLite history preserves opaque page boundaries, replays complete message groups, and retains displayed mobile history until a valid recovery succeeds.

Filesystem transfers still report partial results when an operation fails. POSIX file handles cannot prevent every concurrent rename performed by another process; observed conflicts are reported explicitly.
