# 모바일 동시 PC 연결과 홈·계정 화면

## 변경

기존 PWA는 PC 선택 시 이전 전송을 닫았다. 저장된 PC마다 독립된 인증·스냅샷 전송을 유지하는 pool로 바꾸고, 홈 카드에서 해당 PC의 작업 공간으로 바로 진입한다. 터미널 연결은 선택한 세션에서만 열며 백그라운드 PC에 예열 소켓을 추가하지 않는다.

PC·기기별로 초안과 Chat 상태를 구분한다. 화면의 RPC·사진은 생성 당시 전송과 세대에 묶여 다른 PC로 전달되지 않는다. 삭제·재페어링된 전송의 늦은 콜백은 무시한다. PC 간 같은 세션 번호도 홈의 최근 세션에서 별도 대상으로 취급한다. 저장하는 최근 기록은 기기 ID·세션 번호·그룹 키·시각뿐이다. 연결이 끊긴 PC는 끊긴 상태로 표시하고 세션 입력은 비활성화한다.

홈은 PC 카드와 최근 세션으로 구성한다. 인사·사용량·로그인 설명과 설치 권유를 반복하지 않는다. 설치는 설정에서 제공한다. 계정 화면은 공급자별 계정과 5h/7d 사용량을 표시하고, 남은 시간은 언어 설정과 무관하게 `5h`, `7d`로 표시한다. 알 수 없는 사용량은 0%로 바꾸지 않고 `—`로 남긴다. 만료된 사용량은 다음 조회까지 비운다.

닫힌 시트의 입력칸이 DOM에 남아 자동 갱신을 막던 문제도 수정했다. 시트를 닫으면 내부 입력을 정리한다. 다른 PC에 미전송 초안이 있으면 자동 갱신을 유예한다.

## 검증 범위

- Node 회귀 60개: 독립된 두 인증 연결, 동일 세션 번호, 한 PC 연결 종료, 다른 PC 선택 시 기존 소켓 유지, 삭제 후 늦은 인증·주소 조회, 초안·사진·질문 대상 보호, 계정 수치와 짧은 시간 표기.
- 실제 Chromium과 격리된 v0.1.25 holder/daemon 두 개: 두 PC 동시 연결, 최근 세션의 PC별 열기, PC별 초안 복구, 새로고침 후 두 연결 복구, 계정 화면의 PC 선택, 한 PC 권한 회수 후 다른 PC 연결 유지. 390px와 320px·글자 150%에서 가로 넘침과 사용량 행 높이를 확인한다.
- `mobile_pwa.cjs`: 실제 데몬 E2EE·gzip 에셋·작업 공간 생성·계정 변경·터미널 입력·사진·권한 회수 경로. 테스트 바이너리와 기대 내장 에셋 리비전을 명시해 배포된 데몬과 신규 PWA 조합도 검사할 수 있다.

## 배포 계약

내장 UI의 해시는 와이어 프로토콜 버전과 별개다. 고정 출처 Pages의 조회·런처에서 **실제 호환 검증한** v0.1.24/25 UI 해시만 이번 UI로 안내할 수 있다. 알 수 없는 해시는 그대로 두며 모든 미래 버전의 호환성을 가정하지 않는다. 기존 `/m/<hash>/` 정적 파일은 수정하지 않는다. 인증 정보·PC 주소·데몬이 등록한 원래 해시는 그대로 유지하고, 새 UI의 전체 에셋 해시 확인과 조용한 시점의 전환은 기존 updater를 사용한다. 서버 전환과 UI 배포는 데스크톱 바이너리 릴리스와 구분해 기록한다.

`cloud/mobile/`은 저장소 정책상 비추적 운영 소스다. Pages 변경·검증·기존 에셋 보존 내역은 별도 배포 증거로 남긴다. 이 문서 자체는 배포 완료를 뜻하지 않는다.
